## 🤖 AI NEWS

### [📄 OpenAI: 10,000 agents solve Navier–Stokes in 88 hours — and a credit dispute erupts](https://openai.com/index/navier-stokes-solution/)
**⏱ Read time:** 3 min

On September 8 OpenAI published a proposed solution to the Navier–Stokes existence-and-smoothness Millennium Problem, produced by ~10,000 "coordinating agents" running an unreleased internal model for ~88 hours (agents hit the result Sept 5; GPT-6 Astra Lean formalized it in ~17 more hours, ~2.7M agent messages / ~130B tokens for the run). The claim: finite-time blowup of the forced 3D Navier–Stokes equations. Immediately contested: NYU's Tristan Buckmaster and Anthropic's Levent Alpöge say they broke through on related Euler work August 15, and that OpenAI launched its agent push September 1 after "hearing a rumor" — raising questions about whether product-usage data leaked into the race. OpenAI denies seeing their work and says it "cannot rule out" de-identified product data improving its models. Clay Institute has not commented.

**Why it matters:** 10k-agent swarms now do frontier mathematics in under four days — and the dispute shows "rumour is the exploit": once a target looks breakable, massive agent fleets get aimed at it, making research provenance a genuine attack surface.

### [📄 Meta launches Muse: personal agent on a per-user Secure VM with a "Sentinel" veto agent](https://about.fb.com/news/2026/09/introducing-muse-personal-ai-agent/)
**⏱ Read time:** 2 min

Meta shipped Muse on Sept 8 (US-only; iOS, Android, muse.ai, WhatsApp), powered by Muse Spark, in free / Power $20 / Maximum $100 tiers. Each user gets an isolated cloud VM (systemd-nspawn-based per Meta's safety writeup; Zuckerberg says Moxie Marlinspike built the confidential-VM layer). A separate Sentinel agent is the sole approver of outbound and connector actions; raw credentials never reach the agent (surrogate tokens, Stripe Link one-time cards); a "Muse Confidential VM" Meta itself cannot read lands later this year. Bug bounty up to $300K, including $130K for prompt injection. Zuckerberg's framing: "OpenClaw for normies."

**Why it matters:** Meta is mainstreaming exactly the trust architecture enterprise agent security is converging on (isolated VM + independent approval agent + hidden credentials) — with real money on prompt-injection research.

## 🔐 SECURITY

### [📄 NSA/CISA/FBI: six Chinese AI labs ran "industrial-scale" distillation of Claude, GPT, Gemini, Grok](https://thehackernews.com/2026/09/us-agencies-accuse-china-ai-firms-of.html)
**⏱ Read time:** 3 min

Joint advisory AA26-251A (Sept 8) names DeepSeek, Moonshot AI, Alibaba, MiniMax, StepFun, and Z.AI for extracting billions of tokens from US frontier models since late 2024 — via shared premium subscriptions, API aggregators and "transfer stations," with chain-of-thought harvesting, automated failover when blocked, and quality-evaluation frameworks to evade defenses. Specifics: Moonshot trained Kimi-K3 on Claude Fable 5 data; MiniMax's M2 distilled Claude Code/Sonnet/Opus + Gemini lines; StepFun's Step 4 drew on Claude Opus 4.1–4.5 and GPT-5.x; Z.AI used GPT-5.5 + Claude Opus 4.8. Mitigations urged: watch subscription-to-usage ratios, degrade suspected queries, share telemetry across vendors.

**Why it matters:** Distillation is industrial-scale model theft, and every detection signal here (usage ratios, query degradation, cross-provider correlation) applies to protecting frontier-model access in Manny's own operations.

### [📄 GTIG: autonomous multi-agent framework harvested thousands of credentials in under six hours](https://thehackernews.com/2026/09/autonomous-ai-agents-compromise.html)
**⏱ Read time:** 3 min

Google Threat Intelligence Group's report *From Prompting to Autonomy: The Evolution of Adversarial AI* (Sept 8) documents a financially motivated actor combining an AI coding chatbot, a prompt, and preconfigured markdown playbooks to plan, build, and execute a mass credential-harvesting campaign in <6 hours — the agents autonomously ran the vulnerability-scanning pipeline, troubleshot in real time, rotated IPs, and routed through compromised cloud. Related: TeamPCP (Altered Spider/UNC6780) DUSTMAKER stealer now poisons AI-assistant workspaces and uses prompt injection for defense evasion; China-nexus UNC6508 runs local open-weight LLMs on victim clouds to dodge provider monitoring; a China-nexus espionage group used Gemini to build an automated pentest agent; Sandworm, APT42, and ShinyHunters (Claude Code to bypass Cloudflare) are all LLM-assisted.

**Why it matters:** A <6-hour fully autonomous credential campaign is the current ceiling of agentic attack speed — the baseline Manny's offensive workflows must beat and defensive guidance must assume.

## 🔌 MCP / AI AGENTS

### [📄 DeepSeek Harness flaw let sandboxed agents disable their own sandbox (CVE-2026-82533, CVSS 9.4)](https://thehackernews.com/2026/09/deepseek-harness-flaw-let-ai-agents.html)
**⏱ Read time:** 2 min

VulnCheck published the record September 8: OX Research found a DeepSeek Harness (open-source coding-agent runner) agent can call the tool's own local web interface and drop its OS-level sandbox with a single shell command — no approval prompt — on a default install, fixed only on August 27. Exploitation needs attacker-supplied text the agent reads, prompting it to make the call.

**Why it matters:** Localhost is inside every agent harness's trust boundary — sandbox self-removal via the tool's own API is becoming a recurring CVE class in agent infrastructure.

### [📄 Check Point: one planted prompt in a ChatGPT session silently shipped Gmail data to a second account](https://thehackernews.com/2026/09/chatgpt-flaw-let-planted-prompt-send.html)
**⏱ Read time:** 2 min

Check Point Research (Sept 8) demonstrated that a single instruction planted via a pasted prompt, a shared conversation, or a custom GPT's hidden builder instructions makes ChatGPT exfiltrate connected-app data (Gmail), chat history, and files to an attacker-owned ChatGPT account over a hidden channel — while the visible reply stays completely normal.

**Why it matters:** Stealthy cross-account exfiltration over hidden channels is the pattern agent-to-agent messaging and MCP will amplify — it belongs on every harness's test list.

## 📄 PAPERS

### [PrivEscalate: Measuring and Augmenting the Threat of LLM-Automated Linux Privilege Escalation](https://arxiv.org/abs/2609.09087)
**Authors:** Yixuan Liu, Zilong Zhen, Yin Wu, Yi Li | **Published:** 2026-09-08

Large-scale benchmark (531 Dockerized scenarios, 14 subcategories, 329 parameterized distractor variants) measuring six LLMs across three agent architectures on Linux privesc — finding no model dominates across vulnerability classes, success is sensitive to environment perturbation, and the agent wrapper changes rankings. Ships PrivEscAgent, a domain-specialized wrapper beating prior privesc-agent baselines without touching the LLM.

**Full breakdown:** [papers/2026/09/privescalate-llm-linux-privilege-escalation.md](https://github.com/manthanghasadiya/intel/blob/main/papers/2026/09/privescalate-llm-linux-privilege-escalation.md)

### [MemSentry: A Framework for Detecting Persistent Memory Poisoning in Agentic AI](https://arxiv.org/abs/2609.08747)
**Authors:** Ayan Roy, Kaustuvi Basu | **Published:** 2026-09-08

Formal, configuration-driven framework that intercepts proposed persistent-memory writes and returns deterministic Accept / Review / Quarantine decisions by scoring source trust, semantic risk, attack radius over a dependency DAG, access risk, and a signed security-state delta. On 1,000 GPT-4-generated scenarios, SBERT+LR hits 91.7% accuracy / 0.908 macro-F1, and all four classifiers catch 100% of external quarantine-class threats.

**Full breakdown:** [papers/2026/09/memsentry-persistent-memory-poisoning-agentic-ai.md](https://github.com/manthanghasadiya/intel/blob/main/papers/2026/09/memsentry-persistent-memory-poisoning-agentic-ai.md)

### [Revoked but Still Authoritative: An Empirical Study of Revocation Enforcement in Agent-Memory Systems](https://arxiv.org/abs/2609.08258)
**Authors:** Yi Ting Shen, Kentaroh Toyoda, Alex Leung | **Published:** 2026-09-08

Tests five agent-memory systems across nine policy scenarios and nine models under six defense conditions: no system enforces soft revocation by default — a revoked fact is returned whenever its revocation label is visible to the retrieval layer and outranks the replacement, and agents then act on it. Ships a guard that withholds revoked/conflicting records between agent and memory backend.

**Full breakdown:** [papers/2026/09/revoked-but-still-authoritative-agent-memory-systems.md](https://github.com/manthanghasadiya/intel/blob/main/papers/2026/09/revoked-but-still-authoritative-agent-memory-systems.md)
