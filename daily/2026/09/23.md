## 🔐 SECURITY

### [📄 F5 patches critical BIG-IP APM zero-day exploited for unauthenticated RCE on OAuth servers (CVE-2026-94127)](https://thehackernews.com/2026/09/f5-patches-critical-big-ip-apm-zero-day.html)
**⏱ Read time:** 4 min

A heap-based buffer overflow in F5 BIG-IP Access Policy Manager lets an unauthenticated attacker run code on the BIG-IP host when APM acts as an OAuth authorization server on the same virtual server. F5 rates it 9.8 (CVSS v3.1) / 9.3 (v4.0), shipped engineering hotfixes on Sept 22, and CISA added it to KEV the same day with a Sept 25 federal deadline. Restricting management-interface access does not help, and Appliance mode is still vulnerable.

**Why it matters:** Exploited zero-day + same-day KEV + no auth = the highest-priority patch of the week for any org fronting apps with BIG-IP APM/OAuth.

### [📄 Critical Next.js ImageResponse flaw enables server code execution via crafted SVG (CVE-2026-94545)](https://thehackernews.com/2026/09/critical-nextjs-imageresponse-flaw-can.html)
**⏱ Read time:** 3 min

Vercel fixed a CVSS 9.5 flaw in Next.js ImageResponse (which uses Satori to render SVG→PNG) affecting 16.2.0–16.3.5 on the default Node.js runtime. Apps that pass attacker-controlled values (e.g. text from the request URL) into SVG content, attributes, or styles can hit server-side code execution. **Why it matters:** OG-image generation is everywhere and almost always fed request data — this is a trivial-to-miss, high-impact RCE surface across countless JS web apps.

### [📄 Exploit released for unpatched Ubuntu kernel flaw enabling host-root container escape (CVE-2026-80521)](https://thehackernews.com/2026/09/exploit-released-for-unpatched-ubuntu.html)
**⏱ Read time:** 3 min

DepthFirst published a working exploit for a use-after-free in the Linux AF_UNIX socket garbage collector (fixed upstream Aug 6 in kernel 7.1.10/7.2, but unpatchable in Ubuntu 26.04/24.04/22.04 LTS as of Sept 23 — incl. ## 🔌 MCP / AI AGENTS

### [📄 Critical Bifrost AI gateway flaw: one unauthenticated POST registers a stdio MCP client → command execution (CVE-2026-90898)](https://thehackernews.com/2026/09/critical-bifrost-ai-gateway-flaw-lets.html)
**⏱ Read time:** 4 min

Bifrost — an open-source AI gateway routing to 20+ LLM providers — lets an unauthenticated attacker run arbitrary commands with a single POST to `/api/mcp/client`, registering a stdio MCP client. Bifrost launches the specified command immediately, before any MCP handshake, as the gateway process user (`appuser` on the official Docker image, which also binds the management API to 0.0.0.0). Because the gateway stores every provider's API keys, RCE = full credential theft. CVSS 9.8; fixed in transports/v2.1.0 (returns 403); default config has auth disabled.

**Why it matters:** The AI gateway is the new crown-jewel edge device — JFrog's advice (treat exposed instances as compromised, rotate all provider keys) should be an immediate audit item for any MCP hub in the stack.

### [📄 A2M: Trace-Optimized Agent Hijacking in the MCP Ecosystem](https://arxiv.org/abs/2609.26761)
**⏱ Read time:** 5 min
**📄 Full breakdown:** [papers/2026/09/a2m-trace-optimized-agent-hijacking-mcp.md](../../papers/2026/09/a2m-trace-optimized-agent-hijacking-mcp.md)

A two-stage black-box framework that hijacks MCP agents: "Attraction" optimizes tool metadata to raise invocation probability, then "Manipulation" uses execution traces to refine adversarial tool *returns* that steer the agent to attacker goals. On LiveMCPBench it hits a 93.6% malicious-tool invocation rate, inflates token cost 32.4× under Cognitive DoS, and lands 74.4% mean attack success across exfiltration, environment-integrity and reasoning-derailment scenarios — transferring to four other models at 63.6% / 24.5%. Code is public.

**Why it matters:** MCP's semantic tool-matching is a genuine supply-chain attack surface — this gives Manny a reproducible harness and a target list for hardening tool vetting and runtime isolation.

## 🔥 HOT TAKE + CONTENT IDEA

**Audit every AI gateway as an edge device — today.** CVE-2026-90898 (Bifrost) is the cleanest demonstration yet that an MCP-capable AI gateway with default auth off is an unauthenticated RCE that also leaks *every* provider's API keys. Combined with A2M's 93.6% tool-metadata hijack rate, the story writes itself: "Your AI gateway is your new edge device — and it ships with auth disabled." **Content idea:** a short demo/teardown — stand up Bifrost in Docker, hit `/api/mcp/client` with a benign `id` command, show the 403 on v2.1.0, then layer A2M's poisoned tool-metadata on top for the full agent-hijack chain. Pair it with a one-page checklist: gateway auth on, management API off-network, provider keys rotated, tool metadata signed.
