### [📄 FreeIPA flaw chain lets anonymous clients create reusable admin credentials](https://thehackernews.com/2026/09/freeipa-flaw-chain-lets-anonymous.html)
**⏱ Read time:** 3 min

Red Hat fixed a critical chain (FreeIPA CVE-2026-76578, CVSS 9.8 preliminary) that lets a never-authenticated client create a Kerberos identity of its choosing and land in the administrators group on a default install — reproduced twice by Red Hat. Root cause: FreeIPA's default self-service OTP ACI allows unauthenticated writes, and a 389 Directory Server rule (CVE-2026-76560, 7.5) doing plain-text ownership comparison treats an anonymous client's empty name as matching an empty stored value. An earlier fix (CVE-2026-13097) blocked impersonating the real admin but left the unauthenticated write in place. Fixed in FreeIPA 4.13.4.

**Why it matters:** A no-credentials path to domain-admin-equivalent on Linux identity infrastructure — this is the kind of authz-logic bug (empty-vs-empty matching) that agent-driven code analysis is now finding faster; audit any self-service ACI rules you run.

### [📄 PEEP turns Chrome and Edge into post-compromise backdoors](https://thehackernews.com/2026/09/peep-turns-chrome-and-edge-into-post.html)
**⏱ Read time:** 2 min

SOCRadar disclosed PEEP, a Chromium post-exploitation toolkit masquerading as a "Smart Bookmarks" extension. Its installer injects the extension directly into Chrome/Edge profiles, forging Chromium's own Secure Preferences integrity values to bypass Web Store checks and user prompts. A Native Messaging Host (nm_host.exe) extends it to host-level command execution and file management; it polls C2 every 30s over plaintext HTTP, exfiltrating history, session cookies, and credentials. PEEP derives from the open-source RedExt framework (previously used in GlassWorm attacks); Chinese-language artifacts but no attribution. Post-compromise only — needs prior code execution.

**Why it matters:** The browser profile is now the persistence layer, and forging Chromium's integrity machinery defeats the usual "untrusted extension" detections — add Secure-Preferences and Native-Host anomaly checks to EDR queries.
