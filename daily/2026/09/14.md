### [📄 Malicious Twitch extension "JeetBot" leaked OAuth tokens from ~31,000 users](https://thehackernews.com/2026/09/malicious-twitch-browser-extension.html)
**⏱ Read time:** 3 min

A cross-store extension — **"Twitch Enhanced Viewer | JeetBot"** (Chrome, ~30K users; Firefox, ~604) — forwarded users' live **Twitch OAuth tokens** as an `&auth=` query parameter to operator-controlled proxies, where the token lands in cleartext request logs. Per Socket, the token was forwarded for **every channel a user watched except a hardcoded allowlist of ten Russian-language streamer channels**; earlier v4.x builds POSTed tokens to a dedicated endpoint with backups on `deno.dev`/`deno.net`. The tokens grant access to chat, whispers (private messages), and account settings. The developer pushed a fix (Firefox 85.8.7); the Chrome version was still under review and both listings remained available.

**Why it matters:** A textbook "useful free tool with hidden credential exfil" supply-chain attack — the same trust-the-extension model that agents inherit when they install tooling, with a hardcoded allowlist as the tell.

### [📄 Scan the Skill, Govern the Action — 705 "clean" ClawHub skills nonetheless instruct banned actions](https://arxiv.org/abs/2609.12001)
**⏱ Read time:** 4 min

Over **66,192 public ClawHub skill versions**, the authors find **705 skills across 135 publishers** that *every* scanner *and* the registry's judge rate clean yet which instruct an action prohibited by **CIS Control 2.7 / NIST SP 800-53 CM-11** (92% detector precision on a 100-skill hand audit; one publisher contributes 506 of 705). They also show that of **144 commands a live agent executed while following real skill docs, 34.7% carried a consequence class absent from that document**, and propose a deterministic resolver with **no model in the decision path** feeding a per-(resource, class) trust ledger. Key context: OpenClaw's own scanners overlap on at most 10.4% of combined positives.

**Why it matters:** "Screened and clean" ≠ "permitted here, now, by this operator." This is the strongest empirical case yet for moving agent safety from pre-publish scanning to **runtime, deterministic consequence gating** — and it ships a 64-case obfuscation benchmark.

**Full breakdown:** [papers/2026/09/scan-the-skill-registry-verdicts-runtime-consequence-control.md](../../papers/2026/09/scan-the-skill-registry-verdicts-runtime-consequence-control.md)

### [📄 NovaFabric — tamper-evident, replayable audit evidence for autonomous agent runs](https://arxiv.org/abs/2609.12582)
**⏱ Read time:** 3 min

NovaFabric records an agent run — **without modifying agent logic** — into a portable **Run Capsule** (15-entity schema) sealed with a holistic DSSE signature, RFC 3161 timestamp, Merkle log, and redaction attestation, then re-executable under a four-mode replay protocol and exportable as an independently verifiable **Evidence Bundle**. It targets EU AI Act / ISO 42001 / NIST AI RMF record-keeping expectations. Honest results: mocked replay served 10/10 model responses offline but only **2/10 tool-using workloads** completed on replay; declared-stream completeness **0.652**; the rule pack redacted **14/14** credential types preserving 9/9 decoys; blast-radius queries ran 45.5ms p99 over 10M edges.

**Why it matters:** "Prove what the agent did" is becoming a regulatory requirement and a procurement checkbox — NovaFabric is a concrete reference for the audit-trail artifact Manny's agent-assurance content can demand.

**Full breakdown:** [papers/2026/09/novafabric-tamper-evident-agent-run-evidence.md](../../papers/2026/09/novafabric-tamper-evident-agent-run-evidence.md)
