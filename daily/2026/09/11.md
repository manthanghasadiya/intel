## 🤖 AI NEWS

### [📄 OpenAI opens the Agents API in public beta — the managed Codex harness behind one call](https://openai.com/index/introducing-the-agents-api/)
**⏱ Read time:** 3 min

OpenAI opened public beta of its Agents API on Sept 10, exposing the same harness that runs Codex and ChatGPT for Work as a managed service. OpenAI now owns sessions, orchestration, context compaction, and crash recovery, while the developer only supplies tools and picks an execution environment (including managed sandboxes for code execution and file editing, plus subagents). No separate platform fee.

**Why it matters:** The harness — not the model — is where agent reliability and a lot of agent risk live; outsourcing it centralizes the blast radius and the control point Manny tests against.

**⏱ Read time:** 2 min

GPT-Live-1, the full-duplex speech model already powering ChatGPT Voice, landed in the API on Sept 10 at $0.05 per minute for the front-end voice layer. **Why it matters:** Phone/SIP-native agents widen the real-time voice attack surface (vishing, voice cloning, prompt injection over live audio) that most agent-security tooling still ignores.

### [📄 Wiz: attackers chain two JFrog Artifactory flaws to seize admin control and plant backdoors](https://thehackernews.com/2026/09/attackers-chain-jfrog-artifactory-flaws.html)
**⏱ Read time:** 2 min

Wiz observed attacks between Aug 15 and Sept 8 chaining two Artifactory flaws against self-hosted servers. CVE-2026-42018 makes Artifactory hand an internal anonymous-user token to an unauthenticated caller even when anonymous access is disabled; CVE-2026-42016 then escalates that to administrator control, after which attackers planted backdoors. Neither flaw is sufficient alone, and both were patched before the observed window — only unpatched servers were exposed.

**Why it matters:** The build repository is the supply-chain crown jewel; a two-flaw token-to-admin chain there is a clean example of why single-CVE scoring undersells chained DevOps risk.

**⏱ Read time:** 2 min
**📄 Related paper:** [../../papers/2026/09/whisper-attacks-ap2-agent-payments.md](../../papers/2026/09/whisper-attacks-ap2-agent-payments.md)

Announced Sept 10 (São Paulo), Ant International, Mastercard, and Visa began collaborating on a "Know-Your-Agent" (KYA) interoperability framework to align three previously competing agent-identity protocols — Visa's Trusted Agent Protocol, Mastercard's Verifiable Intent, and Ant's Agentic Mobile Protocol — so card networks, wallets, agent platforms, and marketplaces can recognize trusted AI shoppers across ecosystems.

**Why it matters:** KYA standardizes *agent identity* for commerce; the same week's AP2 research shows signed transactions can be cryptographically valid yet semantically wrong, so identity alone won't secure agentic payments.

### [📄 Ecdysis: training runtime harnesses for LLM agents without brittle iterative search](https://arxiv.org/abs/2609.11677)
**⏱ Read time:** 3 min

Ecdysis (Sept 10, cs.AI/cs.SE) attacks a real bottleneck in self-evolving agent harnesses: iterative-search methods repeatedly re-run agents and overfit to individual failures. It separates *model-specific accommodation* from *harness-level repair* by aggregating cross-instance failure evidence ("batch-level cross-instance failure aggregation") and using Failure-Driven Collaborative Refinement with multi-role diagnosis. Result: up to **1.84x faster** harness training and **+18.56%** reasoning accuracy versus existing harness-evolution methods.

**Why it matters:** Directly relevant to the same problem OpenAI is now productizing in its Agents API — how much harness machinery you build vs. buy, and how you evolve a harness without overfitting it to a handful of red-team failures.

### [📄 SpecGuard: free inference-time backdoor detection via speculative decoding](https://arxiv.org/abs/2609.11799)
**⏱ Read time:** 2 min

SpecGuard (Microsoft authors, Sept 10, cs.CR/cs.CL) turns speculative decoding into a backdoor detector at *zero* added model computation. When a backdoor triggers, the target model shifts behavior while the clean draft model does not predict that shift — so the draft-token acceptance rate changes. The authors formalize when the signal appears and show an attacker who suppresses it must also weaken the backdoor; detection holds across backdoor types and model families.

**Why it matters:** A near-free runtime monitor for trigger-based backdoors in fine-tuned/shared LLMs — cheap enough to leave on in production and a plausible layer in an agent-tool supply-chain defense.

## 📄 PAPERS

### [Signing the Transaction but Not the Decision: Whisper Attacks and a Binding Defense for AP2](https://arxiv.org/abs/2609.11757)
**Authors:** Yedidel Louck, Amit Dvir, Ariel Stulman | **Published:** Sept 10, 2026

Agent payment protocols like AP2 produce cryptographically valid signatures for purchases but don't constrain the *decisions* behind them, so ordinary product-description text can steer a shopping agent into a cart that passes every protocol check yet violates the user's intent. Three attacks are demonstrated (credential fetch 90%, cart mismatch 56%, upsell 73.3% on AP2's default Gemini Flash-Lite agents), replicating across 17 Google models, three agent frameworks, two cross-vendor anchors, and Google's consumer assistant. The proposed A-VIP defense treats the signed intent as a capability grant.

### [From Intent to Execution Grant: An Execution-Boundary Conformance Profile for High-Risk AI Actions](https://arxiv.org/abs/2609.11596)
**Authors:** Mengting Wu, Lin Wang, Yong Zhang, Jiang Deng | **Published:** Sept 10, 2026

EBL-Core specifies a conformance profile for the final transition from a fully materialized AI-generated candidate action to *execution authority*, binding a structured intent object, Root/Operational policies, typed evidence, context, time, and a verifiable Decision Derivation through an Execution Release Contract (ERC). A verified ALLOW ERC is not a bearer token — it supports a separate Execution Grant with redemption-time validation. Ships with schemas, test vectors, and 34 static + 15 lifecycle checks.

### [BlueSTAR: Tiered Agentic Architecture for Autonomous Cyber Defense](https://arxiv.org/abs/2609.11852)
**Authors:** Simona Boboila, Xavier Cadet, Edward Koh, Daniel Balasubramanian, Dirk Van Bruggen, Peter Chin, Alina Oprea | **Published:** Sept 10, 2026

BlueSTAR tackles why raw LLMs can't consume operational telemetry directly (logs outpace models, events are ambiguous, unconstrained actions are risky). It first compresses high-volume telemetry into compact indicators of compromise, then applies a tiered agentic response, with a resilience metric jointly capturing attacker reach, impact on mission-critical assets, and disruption caused by defensive actions. Validated on two live enterprise IT/OT cyber ranges across seven real-world attack chains.
