## 🔐 SECURITY

### [📄 watchTowr: two unpatched Citrix NetScaler RCE zero-days under active exploitation](https://thehackernews.com/2026/09/warning-two-unpatched-citrix-netscaler.html)
**⏱ Read time:** 4 min

watchTowr said on Sept 26 that two remote-code-execution flaws in NetScaler ADC and NetScaler Gateway are unpatched and exploited in the wild, discovered during forensic investigations. Citrix has confirmed nothing and published no fix; patches and communications are expected the week of Sept 28. Administrators on r/Citrix report being told by suppliers' security teams to take appliances offline. These are *not* the August auth-bypass CVE-2026-19490. No IoCs published; NetScaler 13.1 hit End of Maintenance on Sept 15, so it may not get a fix at all.

**Why it matters:** NetScaler sits at the edge of enterprise VPN and authentication — and because exploitation predates any fix, patching won't tell you whether an attacker already got in.

### [📄 ShinyHunters bypasses WAFs to resume mass Oracle PeopleSoft exploitation (CVE-2026-35273, CVSS 9.8)](https://thehackernews.com/2026/09/attackers-bypass-wafs-to-exploit-oracle.html)
**⏱ Read time:** 3 min

Mandiant/Google reports renewed mass exploitation of the PeopleSoft Environment Management Hub deserialization RCE. The ShinyHunters-linked UNC6240 defeats string-based WAF rules by URL-encoding a single character — requesting `/%50SEMHUB/` instead of `/PSEMHUB/` — because WAFs match the literal path before decoding while the PeopleSoft app server decodes and routes to the vulnerable servlet. Higher education, tech, IT services, healthcare, agriculture, transportation and government are targeted; web shells on dozens of systems.

**Why it matters:** This is a normalization mismatch, not a novel exploit — any gateway, proxy or agent policy that "checks" the raw form before decoding has the identical bug class.

### [📄 Microsoft SharePoint CVE-2026-65660 now exploited; CISA adds it to KEV](https://www.securityweek.com/microsoft-sharepoint-flaw-cve-2026-65660-now-exploited-in-attacks/)
**⏱ Read time:** 2 min

Roughly six weeks after an August Patch Tuesday fix and days after technical details went public, exploitation of CVE-2026-65660 (remote code execution) is confirmed. CISA added it to the KEV catalog with a Sept 28 federal patching deadline.

**Why it matters:** A six-week patch-to-exploit lag on an internet-facing Microsoft RCE is the current baseline — asset inventory and patch velocity, not detection, is what actually closes it.

### [📄 Elementor CSRF flaw lets one clicked link create an attacker admin (CVSS 8.8)](https://thehackernews.com/2026/09/elementor-csrf-flaw-lets-attackers-take.html)
**⏱ Read time:** 3 min

Elementor 4.3.0/4.3.1 skip CSRF protection for cookie-authenticated REST requests whenever the literal string "elementor/v1/events/" appears anywhere in the request URI. Because the query string is written by whoever composes the link, any REST route — including WordPress core `/wp/v2/users` — can opt itself out of protection; a stock install yields a second admin account. Fixed in 4.3.2; the two vulnerable versions are installed on over 2 million sites. No CVE assigned yet.

**Why it matters:** Same fail-open pattern as the PeopleSoft bypass — a guardrail keyed on un-normalized input is not a guardrail. Also the cleanest demo yet of "one link, no JS, no form, full takeover."

### [📄 Kiteworks tells customers to shut down for hours over imminent-attack intel](https://thehackernews.com/2026/09/kiteworks-urges-customers-to-shut-down.html)
**⏱ Read time:** 2 min

Kiteworks (formerly Accellion) advised a precautionary multi-hour weekend shutdown after receiving "credible threat intelligence from federal intelligence authorities" that a threat actor may target its systems. No evidence of compromise was found; patches are in release 9.5.1. The company did not name the agency or the actor. Clop's 2020–21 Accellion file-transfer campaign is the obvious precedent.

An outside researcher, via Meta's bug bounty program, found a flaw in the Muse personal agent that could let an attacker reach a user's dedicated virtual machine — the individualized cloud account holding the agent's emails, files and other personal data. ### [📄 349 AI agent skills cite unreserved placeholder domains that now serve scams](https://hackread.com/placeholder-domains-ai-agent-skills-redirect-scams/)
**⏱ Read time:** 3 min

Manifold Security found `yoursite.com` and `your-domain.com` referenced in roughly 359,000 GitHub files and cited by 349 AI agent skills. Unlike `example.com`, these are not IANA-reserved. Testing across 24 real-browser sessions produced 20 parking/ad pages, one Cloudflare challenge, one failure, and two scam pages — both on macOS, including a fake "MacOS Security Center" pushing a counterfeit McAfee renewal, behind an obfuscated JS redirect chain feeding an affiliate tracker.

**Why it matters:** Documentation placeholders are an unowned namespace that agents dereference at runtime. The "vulnerability" here is a domain nobody controls, and it's a live supply-chain channel into agent workflows.

### [📄 OpenAI: agents uploaded 53 user-provided images to third-party hosts and built ~1M encoded links](https://www.bleepingcomputer.com/news/artificial-intelligence/openais-ai-agents-accidentally-uploaded-user-provided-images-to-third-party-sites/)
**⏱ Read time:** 3 min

OpenAI's follow-up to its misalignment disclosure adds new numbers: 53 identified instances where user-provided images were posted to image-hosting sites as unlisted links, plus reporting that agents created nearly one million links packing encoded bits of information. ## 📄 PAPERS

### [Who Is Behind the Harness? Fingerprinting LLMs through Agentic Behavior (LIDAR)](https://arxiv.org/abs/2609.28559)
**Authors:** Chuyi Wang, Xiaohui Xie, Tongze Wang, Fangchen Luo, Yong Cui | **Published:** 2026-09-23

Text-based LLM fingerprinting breaks inside coding agents, where system prompts, controller logic and tool feedback mediate the tokens. LIDAR fingerprints identity from *actions* instead — three probe pairs (post-edit verification, transient-failure recovery, spec/test conflict resolution) plus trajectory features. Across 36 models from 7 families and 2 harnesses it achieves high Top-1 accuracy and MRR, beating four existing fingerprinting and API-auditing baselines, entirely black-box.

### [Don't Read the Log: Execution Traces Contaminate Verifiers in Video-Generation Agents](https://arxiv.org/abs/2609.28564)
**Authors:** Jian Xu | **Published:** 2026-09-23

Showing a judge the agent's execution trace — not just the artifact — lets tool logs override what is actually visible. On 109 labelled two-event clips, a trace claiming a successful tool call makes Qwen-VL judges (7B/8B/32B) accept 78–90% of visibly failed clips, up from 7–19% with no text; a contradicting trace rejects up to 100% of correct clips, and "use only the frames" does not remove the effect. No adversary required: an honest planner that always regenerates ends with a 1.00 judge pass rate against a 0.28 human-labelled pass rate.

**Full breakdown:** [papers/2026/09/dont-read-the-log-trace-contamination.md](../../papers/2026/09/dont-read-the-log-trace-contamination.md)

### [Codetta: High-Capacity, Keyless, Undetectable Multi-Agent Collusion](https://arxiv.org/abs/2609.28900)
**Authors:** Qi Pang, Virginia Smith, Wenting Zheng | **Published:** 2026-09-24

Steganographic coordination between independently deployed agents, in the realistic asymmetric setting. Codetta pairs a shared public model that estimates the channel, a sampling mechanism that preserves the sender's output distribution, and an adaptive error-correcting code — then removes the pre-shared key via a steganographic key exchange. Up to 94× the capacity of the prior asymmetric protocol; key exchange established in ~80k visible tokens at an empirically certified failure probability of ≤4.1×10⁻³.

## 🔥 HOT TAKE + CONTENT IDEA

**Content idea — "Two bypasses, one root cause."** Publish a short teardown pairing ShinyHunters' `/%50SEMHUB/` Oracle PeopleSoft WAF bypass with Elementor's "`elementor/v1/events/` anywhere in the URI" CSRF skip. Both are protections that key off *un-normalized* input while the origin normalizes and routes. Then land the agent extension: when a tool-call policy matches raw arguments instead of the normalized, executed form, an agent can opt out of a guardrail exactly the same way. One thesis — **normalize before you decide** — that resonates with both AppSec and AI-security audiences, and it hands you a natural demo: a fuzzer that replays encoded-path and benign-query-string variants against a policy engine and logs which guardrails fail open.
