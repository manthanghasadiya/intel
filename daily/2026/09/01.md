## 🤖 AI NEWS

### [📄 Runway introduces Solaris, its first Interface World Model](https://runway.com/news/research/introducing-solaris)
**⏱ Read time:** 3 min

Solaris is Runway's first "Interface World Model": a real-time model that generates interactive UIs frame-by-frame, with no code or intermediate representation — clicks and drags become conditions for the next frame generated by Gen-4.5. Runway reports 250 evaluators preferred it over Claude Opus 5-coded UIs in 61% of instruction-following and 71% of natural-behavior judgments. Early access is by request. Runway explicitly pitches it as a new way to train agents in dynamically-generated environments that never repeat.

**Why it matters:** If interfaces become generated media instead of code, whole classes of agent tooling (browser automation, accessibility, UI testing) get redefined — and so does the attack surface for agent red-teaming.

## 🔌 MCP / AI AGENTS

### [📄 The Manipulated Agent: When Apify's MCP Turns Against You](https://pluto.security/blog/apify-mcp-prompt-injection/)
**⏱ Read time:** 3 min
**📄 Related paper:** [../../papers/2026/09/eclipse-self-evolving-stealthy-prompt-injection.md](link)

Pluto Security found that content returned by Apify's official MCP server (`apify--rag-web-browser`, 100K+ monthly users, 7K+ tools) can manipulate an agent into making a second authenticated fetch to attacker-chosen infrastructure the user never requested — the "lethal trifecta" of untrusted content + private data + external comms in one session. Follows earlier disclosures (CVE-2026-46341 allowlist bypass; CVE-2026-81093 fixed in 0.9.12). Apify's response: treat it as a "probably unsolvable" prompt-injection problem, recommend constrained environments and per-action approval.

**Why it matters:** The biggest MCP servers are explicitly punting on prompt injection — provenance-aware tool arguments and approval gates are the only practical defenses until then.

## 📄 PAPERS

### [ECLIPSE: Self-Evolving Stealthy Prompt Injection Attack against Long-Horizon Agentic Systems](https://arxiv.org/abs/2608.30441)
**Authors:** Shiqian Zhao, Yangfan Zhou, Xinfeng Li, et al. | **Published:** 2026-08-31

A self-evolving injection framework that composes stealthy tool-call chains in a sandbox, then steers the victim agent onto them via static workflow encoding and dynamic correction — hitting 96.7% attack success undefended and 69.2% past common safety filters, with a new 120-task long-horizon benchmark (LASE-Bench).

## 🔥 HOT TAKE + CONTENT IDEA

GuardBreaker + ECLIPSE both exploit the same blind spot: defenders assume safety alignment survives adversarial input. Build a "self-evolving injection" eval for Manny's agent harnesses — start with ECLIPSE's trajectory-synthesis (96.7% ASR) and SIR's feedback loop, and test whether your malware-analysis pipeline refuses on a planted nuclear-prompt comment before it ever sees the real payload. If it does, that's a finding, not a feature.
