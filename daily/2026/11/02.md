## 🔐 SECURITY

### [📄 VOLTA infostealer pipes the whole victim dossier into Claude, Gemini and Kimi and asks "what are they worth?"](https://thehackernews.com/2026/11/new-volta-infostealer-uses-claude.html)
**⏱ Read time:** 5 min

Cisco Talos documented VOLTA-AUTODOXER, a Windows stealer that harvests the usual browser, Slack, Outlook, wallet and SSH material, then builds an "evidence bundle" — home address, employer, inferred birth year, card last-4, Slack workspaces, Roblox account valuation — and serializes it to OpenRouter. Requests default to Claude Opus 4.6, falling back to Kimi K2 and Gemini 2.5 Flash through a three-model chain that checks each reply for refusals ("I can't", "I'm not able"). It also greps Gmail for Amazon, DoorDash, Uber Eats, Walmart and PayPal receipts to corroborate the address, and exfiltrates over Telegram in three stages.

**Why it matters:** This is the first widely-documented multi-model refusal-fallback chain in commodity malware. The 240-word "forensic intelligence analyst" prompt is a reusable template — anyone can lift it and point it at a different bundle.

### [📄 Attackers pose as IT support on Teams, then abuse an ESC1 AD CS template to mint a domain-controller certificate](https://thehackernews.com/2026/11/attackers-pose-as-it-support-on.html)
**⏱ Read time:** 4 min

Microsoft detailed two intrusions: attackers called employees from support-themed external tenants, talked them into opening Quick Assist and reading back the connection code, then dropped a portable Python/Bun/Java runtime. In case one they found an ESC1 template, requested certs for three highly privileged accounts, and were signing into a domain controller and running DCSync seconds later. Defender's automatic disruption cut off all but one privileged account — and that one excluded identity was enough to reach a file server and Rclone data to an external SFTP.

**Why it matters:** Certificate-based identity survives password resets and machine wipes, and "partial containment" is a containment failure. Audit ESC1 templates and check whether your break-glass accounts are excluded from automated response — that exclusion is the pivot.

## 🔌 MCP / AI AGENTS

### [📄 Langflow: unauthenticated RCE reachable through MCP tool enumeration (CVE-2026-93680, 9.8)](https://thehackernews.com/2026/11/critical-langflow-flaws-could-let.html)
**⏱ Read time:** 4 min

IBM's bulletin covers four flaws in the AI agent builder — 9.8 auth bypass (CVE-2026-93680), 9.8 arbitrary code execution via improper control of code generation (CVE-2026-110186), 8.8 agent-generated component code that runs OS commands, and a 6.5 credential exposure. Every release 1.0.0–1.12.8 is affected; only 1.13.0 fixes it. IBM describes one flaw as "unauthenticated remote code execution exploitable through model context protocol tool enumeration," and a public Metasploit module already connects to a Langflow MCP endpoint with no credentials, starts a session and lists tools. `LANGFLOW_AUTO_LOGIN` is on by default in 1.12.8.

**Why it matters:** MCP endpoints are becoming the unauthenticated front door for the whole agent stack. If you're red-teaming agent platforms, `tools/list` is a pre-auth reconnaissance primitive — add it to the standard enumeration pass.

### [📄 MoLing MCP server (CVE-2026-62863, 9.6): a malicious web page can send unauthenticated MCP tool calls — loopback binding does not save you](https://github.com/gojue/moling/security/advisories/GHSA-qpgh-hp5g-4vwp)
**⏱ Read time:** 2 min
**📄 Related paper:** [papers/2026/11/tool-call-traces-privacy-mcp.md](../../../papers/2026/11/tool-call-traces-privacy-mcp.md)

In SSE mode, MoLing's `/sse` and `/message` endpoints don't authenticate, and the `mcp-go` dependency sets `Access-Control-Allow-Origin: *`. Any web page can open a cross-origin `EventSource` to `/sse` — including a loopback listener — read the `endpoint` event, steal the `sessionId`, and then drive `/message` to read/write local files or execute commands. Fixed in 0.5.0.

**Why it matters:** This is the cleanest browser-mediated MCP attack published yet: no exploit code, no victim interaction beyond visiting a page, and localhost-only deployments are still fully exposed. Any local agent server that speaks SSE with permissive CORS is in scope.

**Authors:** Moiz Ali, Nafis Karim, Rownak Islam, Jyotirmay Chauhan, Dhruv Kuchhal, Jason Polakis | **Published:** Oct 30, 2026 (IEEE S&P 2027)

Systematically tests agentic browsers against deployed anti-bot defenses, shows most of them fail to detect autonomous agents, then builds a behavioral fingerprint around the Perception-Reasoning-Action loop. ### [How Much Can Tool Calls Reveal About You? Privacy Leakage from Tool-Call Traces](https://arxiv.org/abs/2610.41885)
**Authors:** Donghang Duan, Qingyu Liu, Yifei Liu, Na Zou, Xia Hu, Dongrui Liu | **Published:** Oct 30, 2026

Introduces PrivacyTrace: 1,000 synthetic user profiles, 4,000 agent trajectories, real MCP tools from 25 servers. Protocol-valid tool calls alone let four mainstream LLM attackers infer user attributes at 26.25% versus 17.97% for prior-based guessing; arguments and returned results carry most of the signal, and cross-session linking amplifies it.

**Full breakdown:** [papers/2026/11/tool-call-traces-privacy-mcp.md](../../../papers/2026/11/tool-call-traces-privacy-mcp.md)

### [SecPO: Principled Adversarial Training for Prompt Injection Security](https://arxiv.org/abs/2610.41998)
**Authors:** Sizhe Chen, Yibo Peng, Jaewon Chang, Chawin Sitawarin | **Published:** Oct 30, 2026

Attacks the DPO anchoring problem in Meta-SecAlign (which still hits ~100% ASR under adaptive injections) with a theoretically principled loss against an approximated injection-invariant oracle, plus adversarial training on strong synthesized attacks. Cuts ASR 1.5–14.5x over Meta-SecAlign and another 2.4–4.6x from the loss; 8.8% vs 78.8% AgentDojo ASR@800 with no measurable utility loss across nine benchmarks.
