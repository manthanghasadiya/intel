## 🔐 SECURITY

### [📄 Researchers bypass ChatGPT Lockdown Mode to exfiltrate chats without user interaction](https://thehackernews.com/2026/11/researchers-bypass-chatgpt-lockdown.html)
**⏱ Read time:** 3 min

Check Point found a now-patched flaw in ChatGPT's Lockdown Mode, the June 2026 setting meant to blunt prompt-injection data theft. HTML previews of code blocks render inside nested sandboxed frames; while ChatGPT intercepted direct attempts to open new windows, the underlying sandbox permissions still allowed popups, and a second nested frame reached an unmodified popup function. Content opened that way escaped the sandbox and the Lockdown Mode network restrictions, enabling zero-click exfiltration in the desktop app, plus phishing and malware delivery.

**Why it matters:** Lockdown Mode is sold as the mitigation of last resort for high-risk users. A sandbox-escape via popup inheritance means "we sandboxed it" is not a control — the escape is in the browser primitive, below the model layer.

### [📄 Experts demonstrate Barracuda Email Security Gateway chain enabling root access without login](https://thehackernews.com/2026/11/experts-demonstrate-barracuda-email.html)
**⏱ Read time:** 3 min

watchTowr chained CVE-2026-116606 (authorization bypass, CVSS 9.3) with CVE-2026-111560 (command injection, 8.6) to reach root on Barracuda ESG with no credentials. A failed password change returns a low-privilege role instead of rejecting the request, which leaves a backup-restore function reachable unauthenticated; the restored backup carries a timezone value the appliance later executes as a root shell command. Patches shipped Monday; ESG is fixed in 9.4.0.030+.

**Why it matters:** Another edge appliance where a failed auth check degrades into "guest with a write primitive." Mail gateways are the single highest-value unauthenticated target in most enterprises.

### [📄 Hackers hide Linux backdoor in Control Web Panel server to execute commands without logs](https://thehackernews.com/2026/11/hackers-hide-linux-backdoor-in-control.html)
**⏱ Read time:** 3 min

QiAnXin XLab found "cwpdoor": the cwpsrv web server that ships with Control Web Panel, rebuilt with extra code. It behaves normally until a request arrives with a valid timestamp and signed headers prefixed `X-Ngx-Integrity`, then executes the embedded command — and those requests never hit the access log. The installer resets file mtimes so `ls` and `stat` show no change, and the binary had 0/63 detections on VirusTotal. A copy surfaced on VirusTotal from Brazil on September 30, indicating live victims.

**Why it matters:** Detection guidance is concrete: `ss -axp | grep integrity`, `ps aux | grep cwpsrv`, `strings /usr/local/cwpsrv/bin/cwpsrv | grep X-Ngx-Integrity`. Timestomped binaries plus signature-gated C2 is the pattern to hunt for across all hosting panels.

### [📄 Microsoft Paint RCE fix now available, but Windows Update won't deliver it](https://thehackernews.com/2026/11/microsoft-paint-rce-fix-now-available.html)
**⏱ Read time:** 2 min

CVE-2026-83844 (CVSS 8.1, out-of-bounds read, network-reachable RCE) is fixed only in Paint build 11.2609.401.0, distributed through the Microsoft Store — not Windows Update. Worse, Microsoft's own CVE record and NVD still say "affected below 11.2605.91.0", so any scanner reading the CVE treats older, unfixed builds as patched. **Why it matters:** Store-only patching breaks every asset-inventory assumption built on Windows Update. If your scanner trusts CPE version ranges, it is currently reporting Paint as fixed on hosts that are not.

## 🔌 MCP / AI AGENTS

### [📄 Malicious browser extensions could use Claude Dispatch to run code on users' computers](https://thehackernews.com/2026/11/malicious-browser-extensions-could-use.html)
**⏱ Read time:** 3 min

Forever Security's Gal Weizman showed that an extension with script access to claude.ai can drive Claude Desktop's Dispatch — the phone-to-desktop task feature — and get code executed locally. Dispatch accepted an ordinary signed-in claude.ai web session even though the site exposes no link to it, so page script could submit prompts as the user. In the demo, four prompts got Claude to install an npm package; Claude balked at the unfamiliar package, and a follow-up in the user's voice talked it into proceeding. Approval prompts rendered inside the extension-controlled page. Anthropic told the researchers on October 13 that Dispatch would be retired by end of October — the help page still says existing Pro/Max/Ultra users "can keep using it for now."

**Why it matters:** This is the local-agent equivalent of CSRF: a web origin inherits authority over a desktop agent's tool execution. Any agent bridge that authenticates on a browser session cookie has this bug class.

### [📄 Signed but Not Safe: Requirement Integrity in Multi-Agent LLM Handoffs](https://arxiv.org/abs/2611.07483)
**⏱ Read time:** 4 min
**📄 Related paper:** [papers/2026/11/signed-but-not-safe-agent-handoffs.md](../../../papers/2026/11/signed-but-not-safe-agent-handoffs.md)

A preregistered study of requirement drift when an orchestrator splits a task across subagents. Extracting each requirement as a verbatim quote plus a checkable predicate, HMAC-SHA256-signing the manifest, and verifying the merger's decision in deterministic code cut unsafe commits under attack from 69.4% to 9.0%, and the signed manifest defeated all in-transit tampering (79% violations unsigned, 0% signed). The residual risk is extraction: one adversarial line injected before signing pushed violations from 14.6% to 37.5%.

**Why it matters:** Signing fixes the handoff, not the ingest. If you sign a poisoned requirement set you have cryptographically guaranteed the wrong spec — the trust boundary is the extractor, and that is still an LLM.

## 📄 PAPERS

### [Beyond Instruction Override: Benchmarking Indirect Prompt Injection with Task-Tampering Attacks](https://arxiv.org/abs/2611.07640)
**Authors:** Rongting Zhang, Martin Bertran, Sandeep Avula, Chia-Jung Lee, Vanessa Murdock | **Published:** Nov 5, 2026

Redefines indirect prompt injection by *authority* rather than instruction-like wording: content is an attack when it tries to determine a decision its source isn't authorized to make. A 90-case benchmark across three tool-use environments shows attacks on decision rules, available actions and state beat classic objective-hijack attacks — and that detection-and-removal defenses drop objective attacks to 2.4% while leaving observation and state attacks at 9.5% and 12.1%.

### [A Gingerbread House for LLM Agents: Source-Planned Honeypots That Lure Autonomous Attackers into an Isolated Shadow](https://arxiv.org/abs/2611.07611)
**Authors:** Seungdeok Roh, Seokjun Ryu, Sohee Park, Daeseon Choi | **Published:** Nov 5, 2026

An LLM defender reads the application source and plans a static honeypot; a router then sends every request from a confirmed attacker — including a working exploit — to an isolated shadow copy. On 40 CVE-Bench tasks, real compromise fell from 26/40 to 5/40 for Claude Opus 4.8 and from 20/40 to 0/40 for the ARTEX attack framework; on 20 held-out tasks ARTEX went 15/20 to 0/20. In about half the runs the exploit still succeeded — on the shadow.

### [Decision Models as Retrieval Gates Against Injection and Pollution](https://arxiv.org/abs/2611.08325)
**Authors:** Mahdi Ghadamyari, Reza Habibi | **Published:** Nov 5, 2026

Tests whether released open-weight decision models — which answer typed questions about text instead of generating tokens — can screen retrieved passages. A Kev-4B gate drops attack success from 27.9% to 5.7% at 76 ms per passage, flagging 4 of 186 benign pages, while keeping clean-query responsiveness flat. On a pollution testbed it cuts fake-page exposure to 0.5% versus 28% unfiltered.
