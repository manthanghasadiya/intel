## 🔐 SECURITY

### [📄 Coldcard Firmware PRNG Flaw Linked to $70.2M Bitcoin Theft in 41 Minutes](https://thehackernews.com/2026/08/coldcard-hardware-wallet-flaw-linked-to.html)
**⏱ Read time:** 2 min

A March 2021 firmware integration error in Coldcard — the Bitcoin-only hardware wallet by Coinkite — routed seed generation to MicroPython's deterministic Yasmarang software PRNG instead of the STM32 hardware RNG, leaving effective entropy at ~40 bits (Mk3) and ~72 bits (Mk4/Mk5/Q). Galaxy Research mapped a July 30 sweep that drained 1,082.65 BTC (~$70.2M) from 1,196 addresses in 41 minutes; an attacker who constrains the device UID, timer state, and RNG history can reproduce candidate seeds offline. Coinkite shipped emergency firmware July 31, but patching doesn't repair existing seeds — affected owners must generate new seeds and move coins.

**Why it matters:** A "secure element" wallet was compromised by a build-config macro check (`MICROPY_HW_ENABLE_RNG` existence vs. value) — entropy-source failures are the quietest way hardware security dies.

### [📄 Rails Patches Critical Active Storage Flaw (CVE-2026-66066) With RCE Potential](https://www.bleepingcomputer.com/news/security/rails-patches-critical-active-storage-flaw-with-rce-potential/)
**⏱ Read time:** 2 min

A critical flaw in Rails' Active Storage lets an unauthenticated attacker upload a crafted image that reads arbitrary files — including the process environment with `secret_key_base` and cloud/database credentials — when libvips processes thumbnails, escalating to RCE. Affects Active Storage before 7.2.3.2, 8.0.x before 8.0.5.1, 8.1.x before 8.1.3.1; libvips is the default processor in official Rails Docker images and Debian/Ubuntu setups. PoCs leaked fast, so maintainers pushed disclosure earlier than planned; rotate all exposed secrets and upgrade libvips to 8.13+.

**Why it matters:** Default-config RCE-adjacent file-read in one of the most deployed web frameworks — worth checking any Rails app in Manny's scope for untrusted image upload paths.
