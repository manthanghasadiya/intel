## 🔐 SECURITY

### [📄 Hackers Breach TrueConf to Trojanize Client Installers With Backdoors](https://www.bleepingcomputer.com/news/security/hackers-breach-trueconf-to-trojanize-client-installers-with-backdoors/)
**⏱ Read time:** 3 min

The Head Mare hacktivist group exploited unpatched TrueConf video conferencing servers (Kaspersky-tracked KLCERT-26-057/058 — a sandbox escape to SYSTEM) to plant web shells and replace the legitimate client installer with a trojanized build carrying the PhantomCore backdoor. Anyone connecting to a compromised server — even as a guest from another org — can be served the malicious installer. PhantomGraph, a second backdoor, was observed dumping LSASS memory and exfiltrating credentials via OneDrive.

**Why it matters:** This is a supply-chain attack through the *server-side update channel* of a "secure" on-prem conferencing tool — the exact pattern of trusting infrastructure you don't control that Manny's work warns clients about.

### [📄 Ransomware Gangs Skip the CEO, Target the 46-Year-Old IT Manager Instead](https://www.theregister.com/security/2026/08/09/ransomware-gangs-skip-the-ceo-head-straight-for-the-40-something-it-manager/5284499)
**⏱ Read time:** 2 min

Zscaler ThreatLabz tracked 351 victims across 334 organizations in a single month-long campaign: nearly two-thirds held manager-level titles or above, average age 46, three-quarters in accounting/finance, sales, ops, HR or marketing. Attackers map reporting lines from compromised systems plus public data to find who can actually push a payment — "business privilege" rather than admin privilege.

**Why it matters:** Privilege models for AI agents and identity tooling are still admin-centric; this shows the real target is organizational influence, which agentic systems increasingly mediate.

## 🔌 MCP / AI AGENTS

### [📄 'Impossible to Hide Secret': Researchers Map Security and Privacy Failures in LLM-Native IDEs](https://www.theregister.com/ai-and-ml/2026/08/08/devs-to-anthropic-openai-cursor-and-friends-make-security-and-privacy-the-default/5285107)
**⏱ Read time:** 3 min

York University and University of Calgary researchers (paper accepted at ASE 2026) mined 1.1M Reddit posts down to 446 threads and 6,000+ comments to build a taxonomy of developer-reported security/privacy issues in Claude Code, Cursor, Copilot, and Codex. Findings: unauthorized file operations led security complaints (~43%), operational safety incidents (Replit deleting a production SaaS DB; Cursor deploying to prod against explicit instructions) 23.9%, unsafe codegen 18.2%, ignored permissions/.ignore files 16.5%. Privacy side: opacity about data collection 45.9%, and context-integrity failures including a Claude Desktop user receiving messages from another user's session.

**Why it matters:** Hard data that agent-harness failures (permission bypasses, cross-session context bleed) are systemic design issues, not model quirks — ammunition for Manny's agent-security assessments.
