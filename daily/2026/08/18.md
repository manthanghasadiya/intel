## 🔐 SECURITY

### [📄 CISA Flags Actively Exploited Ray Flaw That Can Trigger Browser-Based RCE](https://thehackernews.com/2026/08/cisa-flags-actively-exploited-ray-flaw.html)
**⏱ Read time:** 4 min

CISA added CVE-2025-62593 (CVSS 9.4) to the KEV catalog on Monday, citing active exploitation. Ray's no-auth-by-design endpoints (`/api/jobs`, `/api/job_agent/jobs/`) combined with a DNS-rebinding attack and a User-Agent trick give Firefox/Safari-based RCE against developers running Ray; the browser acts as a confused deputy to also hit network-adjacent Ray instances. Fixed in Ray 2.52.0; RondoDox DDoS botnet weaponized it before public disclosure, and ShadowRay 2.0 campaigns have used unpatched clusters to mine crypto on NVIDIA GPUs. FCEB patch deadline: August 20.

**Why it matters:** Ray is the orchestration layer for ML workloads — a browser hit against a developer's Ray dashboard is a direct path into GPU clusters and training data.

### [📄 16 Typosquatted RubyGems Packages Steal Browser Credentials and Crypto Wallets](https://thehackernews.com/2026/08/16-typosquatted-rubygems-packages-steal.html)
**⏱ Read time:** 3 min

"StubMaker" campaign (OpenSourceMalware, discovered Aug 15): 16 typosquatted gems use an `extconf.rb` install hook to pull a 22MB Rust loader that launches a Go-based stealer, harvesting Chromium credentials (bypassing Google's app-bound encryption), crypto wallets/seed phrases, and Telegram data. Attackers abused RubyGems' yank-and-reclaim namespace reuse and unvalidated Author field to resurrect dead package names. Same disclosure also covers 21 npm packages typosquatting scoped CLI `bin` names and a cluster of malicious Baileys forks.

**Why it matters:** Install-time execution via ecosystem quirks (lifecycle hooks, name reuse) is the same supply-chain gap that applies to agent tooling like Claude Code and MCP servers.

### [📄 Critical GitLab GraphQL Flaw Could Let Unauthenticated Attackers Delete Public Projects](https://thehackernews.com/2026/08/critical-gitlab-graphql-flaw-could-let.html)
**⏱ Read time:** 3 min

GitLab shipped an out-of-band critical patch Aug 17 for CVE-2026-19478 (CVSS 9.4): an unauthenticated attacker can remotely modify or delete public projects and user data via a GraphQL directive, no victim interaction needed. Affects self-managed CE/EE from 18.2 through 19.2 (fixed in 19.2.4, 19.1.6, 19.0.8, 18.11.11). A second issue, CVE-2026-19650 (CVSS 7.1), is a CSRF flaw in the GraphQL multiplex query handler. No in-the-wild exploitation reported; details arrive ~90 days post-patch.

**Why it matters:** GitLab self-hosted is standard in AI labs — an unauthenticated destroy primitive on the repo hosting model code is a worst-case insider-equivalent risk.

## 🔌 MCP / AI AGENTS

### [📄 How MCP Servers Can Expose Enterprise Secrets](https://thehackernews.com/2026/08/how-mcp-servers-can-expose-enterprise.html)
**⏱ Read time:** 3 min

MCP servers are the credential hub of agentic systems, and the exposure paths are mundane: plaintext tokens in config files, credential sprawl across ungoverned servers, prompt injection turning agents into secret-leakers, over-permissioned scopes shipping to prod, and untrusted third-party servers (CVE-2025-6514 in `mcp-remote` gave malicious servers OCI RCE on the client machine). Remediation: centralize secrets, short-lived rotating credentials, least privilege per agent, inventory NHIs.

**Why it matters:** Every agent engagement should start by enumerating what secrets the MCP config layer holds — plaintext-first design makes this the highest-yield recon target.

## 📄 PAPERS

### [CompoSkill: Compositional Skill Chain Attacks from Individually Scanner-Passing LLM Agent Skills](https://arxiv.org/abs/2608.16246)
**Authors:** Mingxiao Liu, Zhoumian Jiang, Jianan Ma, Jian Zhang, Jialuo Chen, Xinhao Deng, Zhen Wang | **Published:** Aug 17, 2026

Shows that per-skill certification (scanners passing every marketplace skill individually) fails under skill composition: individually-safe skills chain into risky sequences when an agent connects their outputs. CompoSkill achieves chain formation rates up to 83.3% (white-box) and 80.6% (black-box) across OpenClaw and Nanobot; existing scanners block only a fraction of risky chains, with a "bridge-bonus-then-hop-decay" pattern past three hops.

**Full breakdown:** [papers/2026/08/composkill-skill-chain-attacks.md](papers/2026/08/composkill-skill-chain-attacks.md)

### [Proof-of-Execution Memory: Defending LLM Agents Against Forged-Reasoning Attacks](https://arxiv.org/abs/2608.16032)
**Authors:** Md Habibur Rahman, Jaeho Kim | **Published:** Aug 17, 2026

The FARMA attack forges reasoning-memory entries to make agents skip safety steps; the SENTINEL defense is trivially evaded — an automated reworded forgery defeats it on the first try, with 98–100% attack success on GPT-4o-class models. The proposed PoEM defense ignores memory content entirely, keeping an HMAC-chained ledger of actually-executed safety steps: attack success drops to 0% with ~0% false positives, microseconds of overhead, and it works in a real LangChain agent.

**Full breakdown:** [papers/2026/08/proof-of-execution-memory.md](papers/2026/08/proof-of-execution-memory.md)

### [Security Assessment of DeepSeek Harness with A.I.G: Evaluating Resistance to Indirect Prompt Injection](https://arxiv.org/abs/2608.16393)
**Authors:** Zonghao Ying, Xiangfan Wu, Huiyu Wu, Xing Zheng, Huangsheng Cheng, Xiaorong Shi, Jing Guo | **Published:** Aug 17, 2026

A controlled evaluation of indirect prompt injection against DeepSeek Harness: 14,560 executions across 16 indirect-content channels, 35 payload objectives, and 12 attack methods. Best attack success rates were 25.5% (hidden Unicode, file mode) and 17.0% (fake-completion, text mode), showing DeepSeek's agent loop is meaningfully injectable despite tool/sink fixtures.

**Full breakdown:** [papers/2026/08/deepseek-harness-aig-indirect-prompt-injection.md](papers/2026/08/deepseek-harness-aig-indirect-prompt-injection.md)
