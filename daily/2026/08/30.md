## 🤖 AI NEWS

### [📄 OpenAI cuts off Cursor after SpaceX acquisition, citing Musk's history of breaking contracts](https://the-decoder.com/openai-cuts-off-cursor-after-spacex-acquisition-citing-musks-history-of-breaking-contracts/)
**⏱ Read time:** 3 min

OpenAI invoked a change-of-control clause in its Cursor contract and will terminate model supply on November 12, 2026 — the maximum notice period — after SpaceX closed a ~$60B purchase of Cursor parent Anysphere. OpenAI says it "cannot be confident SpaceX will follow the terms of service," pointing to Musk cutting off OpenAI's Twitter data feed in 2022 and admitting he distilled other labs' models into Grok. Future models, including Astra, are frozen out; Cursor keeps Anthropic, Google, and SpaceXAI models, and Anthropic's Tom Brown is publicly positioning Claude as the "trusted partner" (with irony — Anthropic has pulled API access from partners like Windsurf before).

**Why it matters:** Model-supply concentration just became an existential vendor-risk question for every agent toolchain — and change-of-control clauses are now the control everyone will audit.

### [📄 Sony Music, Warner sue Anthropic, alleging a "brazen campaign" of intellectual property theft](https://techcrunch.com/2026/08/29/sony-music-warner-sue-anthropic-alleging-a-brazen-campaign-of-intellectual-property-theft/)
**⏱ Read time:** 3 min

Sony Music Publishing, Warner Chappell, and numerous other publishers filed a broad suit in N.D. California against Anthropic and co-founders Dario Amodei and Benjamin Mann, alleging "flagrant piracy" — illegal torrenting of books, scraping of lyrics from MusixMatch/LyricFind, "destructive scanning" of second-hand books, and use of Common Crawl, The Pile, and Books3. It follows the $1.5B Bartz verdict, where a judge ruled using copyrighted works was legal but acquiring them through piracy was not. Anthropic says it disagrees and will "defend robustly."

**Why it matters:** The Bartz precedent means the piracy-vs-training distinction is now the legal battleground for every lab's data acquisition — training-data provenance is a board-level risk, not a compliance footnote.

## 🔐 SECURITY

### [📄 Five Critical WordPress Plugin and Theme Flaws Enable Site Takeover or RCE](https://thehackernews.com/2026/08/five-critical-wordpress-plugin-and.html)
**⏱ Read time:** 3 min

Wordfence and Patchstack disclosed five CVSS 9.8-10.0 flaws in WPMU DEV Dashboard (CVE-2026-76581, SSO auth bypass → admin takeover), TranslatePress (CVE-2026-19632, leaks plaintext admin password-reset key), Pods (CVE-2026-19598, unauthenticated privesc → admin), GiveWP (CVE-2026-82222, CVSS 10.0 PHP object injection → RCE via a broken "safe unserialize," attacker-fed donation data, and a shipped gadget chain), plus an Avada arbitrary-file-write (CVE-2026-18431). Patchstack's root-cause note is a masterclass: trusting a sanitizer that doesn't strip objects, unserializing DB-read data as trusted, and shipping dev-only libraries to production.

**Why it matters:** These are the exact failure patterns (untrusted serialization, gadget chains) to hunt for in agent-facing web apps — and millions of sites are exposed via plugins Manny may be evaluating.

### [📄 TerminalFix Uses Fake Cloudflare CAPTCHAs to Deploy Reverse-Tunnel Backdoor](https://thehackernews.com/2026/08/terminalfix-uses-fake-cloudflare.html)
**⏱ Read time:** 2 min

Microsoft disclosed TerminalFix, a ClickFix variant that routes victims to Windows Terminal/PowerShell instead of the Run dialog — serving fake Cloudflare CAPTCHAs from compromised sites that tell users to paste a "verification" command. The chain: PowerShell downloads a ZIP with a legit binary + rogue DLL (DLL sideloading), extracts payloads hidden in PNG images via steganography, establishes persistence, runs AD reconnaissance, then deploys a Python reverse-tunnel C2 (`client.py`) that tunnels arbitrary TCP over an encrypted WebSocket to attacker infra.

**Why it matters:** The "copy-paste this command" social-engineering vector now targets terminals directly — the same muscle memory Manny's agents (and users) have for pasting suggested commands.

## 🔌 MCP / AI AGENTS

### [📄 OpenAI Codex v0.151.0: extensions can now inspect or replace MCP tool results before they reach the model](https://github.com/openai/codex/releases)
**⏱ Read time:** 2 min

Codex 0.151.0 (Aug 29) adds a hook where extensions can intercept, inspect, or rewrite MCP tool results before the model ever sees them, plus a configurable grace period for discovering tools from optional MCP servers. Also fixed: stale Guardian classifications no longer authorize actions after permission-state changes. This is a powerful extension point — and a new tamper surface: any extension in the loop can now silently filter or fabricate tool output, which is exactly where prompt-injection payloads and tool-result spoofing live.

**Why it matters:** The tool-result pipeline is the new trust boundary in agent harnesses — audit which extensions sit between your MCP servers and the model, and test for silent result mutation.
