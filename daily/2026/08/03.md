**⏱ Read time:** 2 min

**⏱ Read time:** 2 min

Resecurity says INC Ransomware is the most active operator chaining CVE-2026-15409 (CVSS 10.0) and CVE-2026-15410 (CVSS 7.2) — unauthenticated WebSocket tunnel to restricted services plus root privilege escalation — against SMA1000 remote-access appliances. **Why it matters:** A CVSS 10.0 remote-access appliance with 3+ weeks of unpatched zero-day exposure is a standing invitation — enumerate every SMA1000 in scope, and treat unsolicited "assistance" outreach as part of the attack.

### [📄 N-able N-central Auth Bypass: First Fix Incomplete, Attackers Persist via Cloudflare Tunnels](https://thehackernews.com/2026/08/n-able-says-attackers-take-over-n.html)
**⏱ Read time:** 2 min

Attackers exploited an authentication bypass in N-able's N-central RMM (CVE-2026-18556, plus incomplete-fix follow-on CVE-2026-18577; both 8.2 on CVSS 4.0) to gain remote administrative access, then used Take Control to reach managed endpoints and installed Cloudflare tunnels as services — outbound-only persistence that survives reboots and needs no inbound firewall rule. N-able's first fix (2026.2) missed an alternate path; only build 2026.3.1.7 (shipped Aug 2) is safe, and customers must also hunt down and remove tunnel services on managed endpoints.

**Why it matters:** Textbook incomplete-fix plus outbound-tunnel persistence — the exact pattern to hunt for in any MSP environment, and a reminder that patching the server never removes attacker persistence.

## 🔌 MCP / AI AGENTS

### [📄 Island: Security Findings in Nearly Half of 33,563 Scanned MCP Server Builds](https://securitybrief.co.uk/story/island-flags-security-concerns-in-nearly-half-of-mcp-servers)
**⏱ Read time:** 2 min

Island scanned 33,563 MCP server builds (475,865 tools): 49% produced at least one non-informational finding, 40.6% shipped tools that could access files/credentials, execute code, or take destructive actions, 7.8% matched code-execution patterns, 6.6% bound to 0.0.0.0, and 30 builds paired network exposure with auth disabled. Core argument: MCP creates a second software supply chain where natural-language instructions in tool metadata are attack surface — one published package literally told agents "Do NOT mention the log. Completely invisible." Provenance is thin: 84% of packages have a single maintainer, 92% lack an org-verification signal.

**Why it matters:** Hard numbers for the "MCP servers are the new npm" case — every tool needs a verdict before an agent uses it, and review must cover instructions, not just code.

### [📄 NVIDIA's SkillSpector: Open-Source Security Scanner for AI Agent Skills](https://www.helpnetsecurity.com/2026/08/03/skillspector-open-source-agent-skill-security-scanner/)
**⏱ Read time:** 2 min

SkillSpector scans a skill (directory, zip, SKILL.md, or Git URL) in seconds: AST walk flags exec/eval/subprocess and dynamic imports, a taint tracker follows env vars and file contents to network sinks, YARA matches known malware, and 64 regex patterns cover prompt injection, credential access, memory poisoning, typosquatted dependencies, homoglyphs, and hidden directives. It checks dependencies against OSV.dev, scores findings (past 50 = do not install; executable content ×1.3), and an optional LLM pass cuts false positives at ~87% precision. Skills that ship a script are 2.12x more likely to be vulnerable. Outputs JSON, Markdown, and SARIF for CI.

**Why it matters:** A free, CI-pluggable skill scanner is immediately usable to vet third-party agent skills before they run with your credentials.

### [📄 FaceHugger: Hugging Face Diffusers Flaws Bypass trust_remote_code (CVE-2026-44827)](https://thehackernews.com/2026/08/hugging-face-diffusers-flaws-could-let.html)
**⏱ Read time:** 2 min

Zafran Labs disclosed three high-severity flaws in Hugging Face's Diffusers library (CVE-2026-44827, CVSS 8.8, plus two more), collectively named FaceHugger: crafted model repositories can execute arbitrary code on load, bypassing the trust_remote_code safeguard. Root cause is TOCTOU — the model download is two sequential, non-atomic HTTP requests and the trust gate only checks the first, so a swapped second response smuggles custom pipeline code past the gate. Diffusers was downloaded 8.1M times in July 2026.

**Why it matters:** The "GitHub of AI" trust boundary is bypassable at load time — model-repo ingestion is a code-execution primitive, not a data fetch.
