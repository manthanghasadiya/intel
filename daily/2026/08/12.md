## 🔐 SECURITY

### [📄 Malicious LiteLLM Releases Tied to Trivy Hack May Have Exposed 2,100+ Organizations](https://thehackernews.com/2026/08/malicious-litellm-releases-tied-to.html)
**⏱ Read time:** 4 min

Two poisoned LiteLLM releases (1.82.7/1.82.8) sat on PyPI ~40 minutes on March 24, shipping a `litellm_init.pth` file that ran at interpreter startup in any Python process — harvesting env vars, SSH keys, cloud credentials, K8s tokens, and DB passwords (including OPENAI_API_KEY/ANTHROPIC_API_KEY), exfiltrated to `models.litellm[.]cloud`. CloudSEK's captured dataset (~434,000 files) maps potential exposure to 2,500+ orgs including NVIDIA, Cisco, Deloitte, Volkswagen, FedEx, Siemens, and X Corp. The releases were published using a PyPI token stolen in the Aqua Trivy supply-chain compromise (CVE-2026-33634, CISA KEV since March 26); FBI's July FLASH-20260702-01 warns stolen credentials are still being weaponized. Notably: an unpinned transitive dependency — including one pulled by an agent framework — could deliver the package with no one choosing it.

**Why it matters:** LiteLLM is the default AI gateway in countless agent deployments; a 40-minute poisoning window with interpreter-startup execution means any shared host that ever installed it should treat every long-lived secret as compromised.

### [📄 Microsoft Patches 398 Flaws Including a Windows Driver Zero-Day Under Active Attack](https://thehackernews.com/2026/08/microsoft-patches-398-flaws-including.html)
**⏱ Read time:** 3 min

August Patch Tuesday closes 398 CVEs (62 Critical per ZDI), led by CVE-2026-68820 — a use-after-free in `afd.sys` (WinSock kernel driver) exploited in the wild; Check Point attributes it to Lazarus' Operation Dream Job campaign. Four unauthenticated, zero-interaction 9.8 RCEs follow: Windows DNS Server (stack overflow, ZDI calls it wormable), Windows Deployment Services (TFTP), Microsoft QUIC, and HPC Pack. August also ships the RCE half (CVE-2026-63520) of the SharePoint chain whose auth-bypass half (CVE-2026-55040) landed in July.

**Why it matters:** The exploited-before-patch driver bug plus four no-click server RCEs is the patch-priority list for any Windows-heavy environment Manny touches — and the SharePoint chain closure is the same chain Rapid7 found with AI-agent help (see Agents section).

**⏱ Read time:** 2 min

QUIRSO found active exploitation of CVE-2026-59310 (CVSS 9.8, directory traversal → RCE in vCenter, patched late July): path traversal followed by a malicious cron job installing `reverse_ssh` for persistent outbound C2. 361 unique victim IPs across 47 countries (Germany, US, Turkey, Iran, France lead), first contact Aug 3 — five days after disclosure. ## 🔌 MCP / AI AGENTS

### [📄 A Gateway Architecture for Enterprise MCP Authentication](https://arxiv.org/abs/2608.10760)
**⏱ Read time:** 2 min
**📄 Related paper:** [../../papers/2026/08/mcp-gateway-enterprise-auth.md](link)

Production report from an industry deployment of a centralized MCP gateway: a single aggregation/governance/auth layer fronting every downstream MCP server. Introduces a two-axis auth model (persona — interactive user vs. non-user automation — crossed with auth mechanism), identity delegation, and unified offboarding across the fleet, addressing the "zero to dozens of internally built MCP servers in a year" governance crisis.

**Why it matters:** This is the missing architecture doc for the exact problem Manny sees in every enterprise agent rollout: per-team MCP servers with inconsistent auth and no way to revoke a departing employee's agent access.

## 🔥 HOT TAKE + CONTENT IDEA

LiteLLM, the SharePoint chain, and the MCP gateway paper land on the same axis: **the AI gateway layer is the new software supply chain** — one poisoned PyPI package with interpreter-startup execution, and every long-lived secret on the host is gone. Content idea for Manny: a "gateway hardening + red-team checklist" — inventory unpinned transitive deps (an agent framework can silently deliver a poisoned gateway), audit for `.pth`-style startup hooks, verify PyPI publish-token hygiene and short-lived credentials, and test whether MCP traffic transits a centralized auth gateway with per-request audit (per the new paper). One theme: **gateways concentrate risk; treat them like domain controllers.**
