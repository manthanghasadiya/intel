## 🔐 SECURITY

### [📄 Gitea RCE (CVE-2026-60004, CVSS 9.8) added to CISA KEV amid active exploitation](https://thehackernews.com/2026/08/critical-gitea-rce-actively-exploited.html)
**⏱ Read time:** 2 min

CISA added CVE-2026-60004 to its KEV catalog on Tuesday after confirming in-the-wild exploitation. The flaw lets attackers abuse Gitea's diffpatch endpoint to plant a malicious Git hook from repository-controlled content and execute code on the host (Gitea ≤ 1.27.0; fixed in 1.27.1). One reported attack dropped a miner-like dropper. Self-hosted Gitea instances are a prime target precisely because they hold source code and CI secrets.

**Why it matters:** Git infrastructure is the upstream of the whole software supply chain — a pre-auth-ish RCE here is the same class of "compromise the forge, own the repos" play that defines modern supply-chain attacks.

### [📄 miniOrange SAML SSO auth bypasses (CVE-2026-61979, CVE-2026-15981) exploited for WordPress admin takeover](https://thehackernews.com/2026/08/attackers-target-miniorange-saml-flaws.html)
**⏱ Read time:** 2 min

Attackers are actively scanning for two CVSS 9.8 auth bypasses in the miniOrange SAML 2.0 SSO plugin. Both allow forging SAML responses — chained, they hand over a valid WordPress admin session with no credentials and no MFA. Patching is messy: miniOrange ships seven independently versioned editions under one WordPress.org slug, so many paid installs weren't flagged as vulnerable by databases until exploitation was underway.

**Why it matters:** SAML-signature-validation bugs remain a reliably weaponizable class, and the multi-edition distribution problem shows how plugin packaging itself can blind vulnerability management.

## 🔌 MCP / AI AGENTS

### [📄 Marimo notebook flaw (CVE-2026-75149) runs attacker-supplied MCP commands before cells execute](https://thehackernews.com/2026/08/marimo-notebook-flaw-could-run-mcp.html)
**⏱ Read time:** 2 min

Marimo fixed CVE-2026-75149 (CVSS 8.7/8.8), a code-injection flaw in its notebook configuration handler: a crafted notebook can embed an attacker-controlled MCP server command that marimo launches as a local subprocess the moment the file is opened in edit mode — before any cell runs. No authentication required beyond tricking a victim into opening a notebook.

**Why it matters:** Notebooks are the default carrier for data-science agents, and this is a clean supply-chain-style MCP execution primitive: open the file, get code execution via the MCP bootstrap path.

## 📄 PAPERS

### [Beyond the Stability-Exploration Dilemma: Environmental Regularization for LLM Policy Optimization](https://arxiv.org/abs/2608.23311)
**Authors:** Xianlei Zhou, Xiangdi Meng, Yu He, Tianyu Qi, Shuyan Guan, Xianli Zhang, Jian Zhang, Xin Li, Qika Lin, Jun Liu | **Published:** Aug 25, 2026 (EMNLP 2026)

Argues the standard Policy-KL regularizer in LLM RL puts practitioners in a double bind — constrain responses and eat the exploration budget, or drop it and lose drift control. ERPO moves regularization to the input side: as training progresses, the model's likelihood over training queries drifts from its pre-RL reference, silently destabilizing optimization, so they regularize the query distribution instead.

**Full breakdown:** [papers/2026/08/erpo-environmental-regularization-for-llm-policy-optimization.md](link)

### [Recursive Experiential-Working Memory Evolution for Long-Horizon Agent Harnesses](https://arxiv.org/abs/2608.24876)
**Authors:** Zhaochen Yu, Yingcheng Wu, Zhenfei Yin, Kaiyuan Chen, Zhe Zhao, Mengdi Wang, Shuicheng Yan, Ling Yang | **Published:** Aug 25, 2026

Recuris separates agent memory into experiential (long-term skill/knowledge) and working (current task state) stores, with working memory recursively selecting skills from experiential memory — grounding each step in current needs so recursive self-improvement doesn't degrade as histories grow.
