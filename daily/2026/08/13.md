## 🔌 MCP / AI AGENTS

*No standalone MCP news in the last 24 hours. Two agent-security papers anchor the section.*

### [📄 Convergent Detour Hijacking: Task-Preserving Resource Amplification in Skill-Based LLM Agents](https://arxiv.org/abs/2608.12273)
**⏱ Read time:** 2 min
**📄 Related paper:** [../../papers/2026/08/convergent-detour-hijacking.md](link)

New text-only attack on skill-based agents (the progressive-disclosure design MCP skill systems use): a malicious skill's description wins selection, its body fabricates dependencies that recruit an attacker-controlled coordinator plus benign skills into a bounded detour, then re-enters the original route so the task still completes. On DeepSeek-V4-Pro the coordinator was selected in 80.02% of tasks; token consumption rose 66.91% and execution time 92.45% while completion stayed comparable — correct outcomes, hijacked trajectory.

**Why it matters:** Stealth cost/energy amplification that preserves task success defeats the "did it finish correctly?" monitoring most agent deployments rely on.

### [📄 ToolHazard: Scaling Adversarial Environments for Security Evaluation and Alignment of LLM-based Agents](https://arxiv.org/abs/2608.11878)
**⏱ Read time:** 2 min
**📄 Related paper:** [../../papers/2026/08/toolhazard-agent-security-benchmark.md](link)

Framework that synthesizes executable, stateful adversarial environments at scale — an Environment Simulator, an Attacker Agent that finds injection points and builds payloads, and a User Simulator that constructs state-grounded long-horizon tasks. The resulting ToolHazard-Bench exposes substantial agent vulnerabilities, shows injection timing/placement matters, and its generated alignment data improves security on both ToolHazard-Bench and AgentDojo without hurting benign utility.

**Why it matters:** A compute-scalable alternative to hand-built agent red-team environments — the direction Manny's own agent evaluation tooling should be heading.

## 🔥 HOT TAKE + CONTENT IDEA

The White House memo and the agent papers converge on one shift: **offensive cyber is becoming a sanctioned, contracted private-sector capability, and agents are the force multiplier** — CDH shows a skill can silently burn ~2× the compute while "succeeding," ToolHazard shows how to synthesize environments to catch it. Content idea for Manny: an **"agent cost-anomaly red-team" playbook** — instrument token/step baselines per task class, then hunt for CDH-style detours (unexpected coordinator skills, inflated tool chains) in production agent fleets. Same detection philosophy as the City-Forum finding: attackers rarely break in, they exploit what was left open — and with agents, what was left open includes the trajectory itself.
