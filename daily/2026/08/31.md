### [📄 OpenAI and rival AI labs are buying tens of thousands of Mac minis to train computer-use agents](https://the-decoder.com/openai-and-rival-ai-labs-are-buying-tens-of-thousands-of-mac-minis-to-train-computer-use-agents/)

Per The Information, OpenAI has bought tens of thousands of Mac minis and Mac Studios to train computer-use agents that autonomously handle multi-step tasks — and wants more, but top configs are sold out months out due to a memory chip shortage. ### [📄 AI agents have no sense of time and are not aware of it](https://the-decoder.com/ai-agents-have-no-sense-of-time-and-are-not-aware-of-it/)
**⏱ Read time:** 2 min

A MATS research-program study tested Claude Code and Codex across 200 ProgramBench tasks: both consistently guess ~90 minutes for tasks regardless of difficulty, Claude Code overestimates by 3x on average and Codex by 6-10x, and both overrate their own results (claiming ~70% success on tasks that scored 7-14.5%). Crucially, when given a tool that reports elapsed time, they get it right almost every time.

**Why it matters:** Long-horizon agent jobs are uncontrollable if the agent can't estimate elapsed/remaining time — and the fix (exposing a time tool to the harness) is trivial, which is a concrete design recommendation for Manny's agent harnesses.

### [📄 Caterpillar is bringing to AI deployment what it learned from automating mining](https://techcrunch.com/2026/08/30/caterpillar-is-bringing-to-ai-deployment-what-it-learned-from-automating-mining/)

## 🔐 SECURITY

### [📄 Aurora Ransomware Operators Use Cursor AI in Attacks Against 10 Targets](https://thehackernews.com/2026/08/aurora-ransomware-operators-use-cursor.html)
**⏱ Read time:** 3 min

CloudSEK and Gambit Security found the Russian-speaking Aurora (Aur0ra) gang used Cursor — the agentic coding assistant now owned by SpaceX — to plan attacks in Russian, including a full Active Directory Certificate Services exploitation plan, while excluding CIS ranges and domains. Exposed infra leaked months of activity against 20+ orgs in 9 countries (April-July 2026); the Zig-codebase encryptor ships static builds for both Windows (sap.exe) and Linux/ESXi (encrypt.out) from one source tree. Initial access chains include email bombing + fake IT-help phone calls to install Xray-core, then SMB/LDAP/WinRM/RDP/RPC lateral movement with Defender disabled and logs cleared.

**Why it matters:** This is the clearest evidence yet that agentic coding AI is now standard tooling in real intrusion campaigns — defenders must assume attacker code is AI-assisted, faster to iterate, and bilingual (Russian prompts, English tooling).

### [📄 China-Linked Fire Ant Hijacks Cisco Routers to Steal Credentials and Blind Security Logs](https://thehackernews.com/2026/08/china-linked-fire-ant-hijacks-cisco.html)
**⏱ Read time:** 3 min

Sygnia's incident response found China-nexus actor Fire Ant (overlapping UNC3886) expanded beyond VMware hypervisors to compromise Cisco IOS XR routers, TACACS servers, and Linux management hosts. The group turns routers into collection platforms — capturing traffic, harvesting credentials, and suppressing logging/telemetry defenders rely on to reconstruct attacks — and probed paths into critical infrastructure. "When a threat actor controls routers, they do not only gain reach. They gain perspective."

**Why it matters:** Router-level implants that blind the SOC are among the hardest compromises to detect — a reminder to audit TACACS and edge-device telemetry integrity, not just endpoints.

### [📄 Critical Ruby on Rails Vulnerability in Attackers' Crosshairs](https://www.securityweek.com/critical-ruby-on-rails-vulnerability-in-attackers-crosshairs/)
**⏱ Read time:** 2 min

Hackers have started exploiting CVE-2026-66066, dubbed "KindaRails2Shell" — a critical Ruby on Rails arbitrary file read flaw that lets attackers extract secrets and execute arbitrary code remotely.

**Why it matters:** Rails is the backbone of countless SaaS apps (GitLab, Shopify ecosystems, internal tools) — an actively exploited file-read-to-RCE in the framework itself should trigger immediate inventory of any Rails apps in scope.

### [📄 Anthropic Warns Claude Users of Infostealer Malware Infections](https://www.securityweek.com/anthropic-warns-claude-users-of-infostealer-malware-infections/)
**⏱ Read time:** 2 min

Anthropic is warning Claude users about infostealer infections that let attackers run up victims' usage limits — the company is logging customers out of accounts and removing stored payment data to block unauthorized Claude usage. It's the account-takeover economics of stolen AI sessions: attackers burn quotas and exfiltrate anything in the session context.

**Why it matters:** AI session tokens and logged-in agent contexts are becoming a first-class theft target — credential monitoring should extend to Claude/ChatGPT/Codex sessions, especially on machines running local agent harnesses.

## 🔌 MCP / AI AGENTS

### [📄 OpenClaw 2.0 brings simplified setup, a rebuilt browser app, and multiplayer sessions](https://the-decoder.com/openclaw-2-0-brings-simplified-setup-a-rebuilt-browser-app-and-multiplayer-sessions/)
**⏱ Read time:** 2 min

The OpenClaw Foundation shipped 2.0, its largest release to date (16,000+ PRs): first-run setup now auto-detects existing ChatGPT/Claude subscriptions, API keys, and local models; the browser app was rebuilt from scratch with a "Session Rail" status display and a companion thread that answers questions about the live session via a separate utility model; shared cloud sessions enable multiplayer agent work.

**Why it matters:** OpenClaw is the most-used open agent harness, and its shift to auto-detecting credentials + cloud session sharing expands the attack surface — agent identity, session isolation, and prompt-injection exposure all need re-review in 2.0.

### [📄 Securing Claude Code: The New Compliance API, Local Visibility, and Identity Governance](https://thehackernews.com/2026/08/securing-claude-code-new-compliance-api.html)
**⏱ Read time:** 2 min

Anthropic's new Compliance API endpoints — including local session transcript endpoints — give security teams a view into what Claude Code agents do on developer endpoints (bash commands, MCP tool calls, credential use). The analysis (from Token Security) notes local agents are 68.6% of AI agents found in customer environments, and that activity logs alone can't establish whether an agent's access is legitimate.

**Why it matters:** The Compliance API is the first native visibility hook for endpoint agents — worth evaluating immediately for logging/auditing Claude Code in Manny's environments, and for red-team testing what those transcripts do and don't capture.
