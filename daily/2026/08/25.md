## 🔐 SECURITY

### [📄 Actively Exploited Oracle WebLogic Flaw (CVSS 10.0) Lets Unauthenticated Attackers Access Critical Data](https://thehackernews.com/2026/08/actively-exploited-oracle-weblogic-flaw.html)
**⏱ Read time:** 2 min

CISA added CVE-2026-21962 to its KEV catalog Monday, citing active exploitation; the improper-access-control flaw in Oracle HTTP Server and WebLogic Proxy Plug-in gives unauthenticated HTTP attackers create/delete/modify access to critical data. Patches shipped in January 2026, but GreyNoise and CloudSEK have tracked exploitation attempts since — including a lone IP hammering WebLogic alongside Ivanti, GNU InetUtils, and GLPI flaws.

**Why it matters:** Unauthenticated CVSS 10.0 with a 7-month-old patch and ongoing exploitation — a reminder that patch lag, not disclosure, is the vulnerability.

### [📄 Mirage2FA Surge Hits 4,500 US and EU Companies, Abusing Microsoft 365 Login Flows](https://thehackernews.com/2026/08/mirage2fa-surge-hits-4500-us-and-eu.html)
**⏱ Read time:** 2 min

ANY.RUN details the Mirage2FA phishing-as-a-service campaign (2024–2026): it abuses legitimate Microsoft 365 login flows to bypass 2FA, stealing passwords and session cookies. Potentially 48% of targeted addresses compromised, ~4,532 org domains hit, 9,000+ compromise events; tech, manufacturing, and education most targeted, US 63.7% of victims.

**Why it matters:** Phishing kits that defeat 2FA via session theft are the baseline threat model for any identity work, including agent OAuth flows.

### [📄 24 npm Packages Abuse unpkg Mirrors to Host Fake Cloudflare CAPTCHA Pages](https://thehackernews.com/2026/08/24-npm-packages-abuse-unpkg-mirrors-to.html)

### [📄 InjecMEM: Memory Injection Attack on LLM Agent Memory Systems](https://arxiv.org/abs/2608.23471)
**⏱ Read time:** 2 min
**📄 Related paper:** [../../papers/2026/08/injecmem-memory-injection-attack-on-llm-agent-memory-systems.md](link)

A single crafted interaction with an agent (no read/write access to its memory store) can poison retrieval so later queries steer toward attacker-chosen output — effective across memory systems, backbones, and under memory drift.

**Why it matters:** Persistent memory is becoming a default agent subsystem; this shows it is a first-class injection channel, not a safe cache.

### [📄 When "Do Not" Is Not Deny: Security Rules in CLAUDE.md vs Built-In Controls](https://arxiv.org/abs/2608.23550)
**⏱ Read time:** 2 min
**📄 Related paper:** [../../papers/2026/08/when-do-not-is-not-deny-security-rules-in-claudemd-vs-built-in-controls.md](link)

Across 481 public CLAUDE.md files, only ~4–16% of written security rules have a matching built-in control (4.4% under the strictest match) — natural-language "do not" rules are a write-only channel with no enforcement feedback.

**Why it matters:** Agent policy files look like controls but mostly aren't; audit tooling must distinguish aspirational rules from enforced ones.

## 🔥 HOT TAKE + CONTENT IDEA

Agent memory is the new injection surface: with OpenAI absorbing Instant (memory/state infra) the same week InjecMEM shows single-interaction memory poisoning, the practical question isn't "can memory be attacked" but "how do you detect a poisoned memory you can't read." Content idea for Manny: build a memory-integrity checker for MCP-backed agents — audit what a memory system retrieves for a probe query set, flag records that steer output, and ship it as a defensive tool before the first big agent-memory breach makes the news.
