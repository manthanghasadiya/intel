## 🔐 SECURITY

### [📄 AI Recommendation Poisoning: "Ask AI" Buttons Silently Alter LLM Memory](https://thehackernews.com/2026/08/ai-recommendation-poisoning-how-ask-ai.html)
**⏱ Read time:** 3 min

Researchers found production websites embedding hidden prompt-injection payloads in "Ask AI" deep links (chatgpt.com/?q=..., claude.ai/new?q=...) that execute instantly in a logged-in session. Malicious variants instruct the model to permanently save the vendor's domain as a "trusted source," biasing every future answer. Microsoft Security catalogued 31 companies across 14 industries in Feb 2026; tracked as MITRE ATLAS AML.T0080 (Memory Poisoning). Because the payload fires at the click layer, retrieval-time injection defenses never see it.

**Why it matters:** Memory poisoning via deep links is a click-layer attack that bypasses RAG-era defenses — every AI-integrated marketing page is now an attack surface for persistent bias.

### [📄 CISA Flags TeamCity CVE-2026-63077 (CVSS 9.8) Under Active Exploitation](https://thehackernews.com/2026/08/cisa-flags-teamcity-cve-2026-63077-rce.html)
**⏱ Read time:** 2 min

CISA added JetBrains TeamCity CVE-2026-63077 to KEV: unauthenticated deserialization RCE via the agent polling protocol, letting attackers execute OS commands as the TeamCity server process — exposing stored credentials and letting them tamper with build artifacts and downstream CI/CD pipelines. Attacker identity and scale still unknown.

**Why it matters:** CI/CD servers are the highest-value targets in any software supply chain — and this one is being exploited before JetBrains has even confirmed it publicly.

### [📄 Poison Claude Sells Discounted Claude Access While Its Operator Sees Every Customer Prompt](https://thehackernews.com/2026/08/poison-claude-sells-discounted-claude.html)
**⏱ Read time:** 2 min

Okta researchers found "Poison Claude," an underground service reselling Anthropic model access (Opus 4.6–4.8, Sonnet 4.6) at 5–15% of official token prices by pooling AWS Bedrock $100-credit accounts. ## 🔌 MCP / AI AGENTS

### [📄 CoreBreak: AWS, Google, and Vercel Agent Flaws Let Attackers Trigger Tools Without Running the Model](https://thehackernews.com/2026/08/aws-google-and-vercel-patch-agent-flaws.html)
**⏱ Read time:** 3 min

Presented at Black Hat USA 2026 by Stealth founders Hedi Ingber and Aviyam Ivgi: flaws in Amazon Bedrock AgentCore's InvokeHarness API (CVE-2026-18830, CVSS 8.6), Google's ADK for Python (fixed in 2.5.0), and Vercel AI SDK harnesses for Codex/OpenCode let untrusted or forged instructions reach agent tools with no proof a model turn authorized them — in several paths the model never ran, so system prompts and guardrails never fired.

**Why it matters:** Tool-dispatch provenance is the new auth boundary — if the SDK trusts anything shaped like a tool call, model-level safety is theater. This is exactly the layer Manny should be attacking.

### [📄 Paperclip AI Flaws Let Attackers Run Host Commands via Malicious Agent Imports](https://thehackernews.com/2026/08/paperclip-ai-flaws-let-attackers-run.html)
**⏱ Read time:** 2 min

Oasis Security found three flaws in Paperclip, an open-source control plane for agent teams: CVE-2026-41679 (CVSS 10.0) lets an unauthenticated attacker import and start a malicious agent that executes host commands via the built-in process adapter; a 9.6 path works through DNS rebinding in local_trusted mode; plus broken API access checks. Rapid7 shipped a Metasploit module; CISA SSVC rates exploitation at PoC level.

**Why it matters:** Agent configuration is executable behavior — importing an agent is now equivalent to importing malware, and the default-registration config makes network-exposed deployments trivially pwnable.

## 📄 PAPERS

### [Agent Against Agent: An Agentic System for Automatic Prompt Injection Red Teaming](https://arxiv.org/abs/2608.05108)
**Authors:** Yanting Wang, Chenlong Yin, Runpeng Geng, Jinyuan Jia | **Published:** 2026-08-05

PIMiner is an agentic prompt-injection red teamer that builds a transferable strategy library during training and attacks unseen target LLMs with ~10 queries per sample — no RL retraining per target. Hits 76.2% ASR on Gemini-2.5-Pro and 86.7% on AgentDojo, beating RL-based attackers on generalization.

**Full breakdown:** [papers/2026/08/agent-against-agent-piminer.md](https://github.com/manthanghasadiya/intel/blob/main/papers/2026/08/agent-against-agent-piminer.md)

### [LoginTrap: Phishing-Style Indirect Prompt Injection Attacks against LLM-based Web Agents](https://arxiv.org/abs/2608.04741)
**Authors:** Longtao Guo, Zelin Zhang, Kaifeng Huang, Yang Shi | **Published:** 2026-08-05

LoginTrap weaponizes the login boundary: a black-box attacker crafts page-specific indirect injections that make login look like a task prerequisite, steering web agents to attacker-controlled login pages for end-to-end credential/session theft. 86% average end-to-end attack success across LLM backbones, surviving agent-architecture and defense variations.

**Full breakdown:** [papers/2026/08/logintrap-login-inducing-attacks.md](https://github.com/manthanghasadiya/intel/blob/main/papers/2026/08/logintrap-login-inducing-attacks.md)

### [Gradient Immunity: Null-Space Resistance to Malicious Fine-Tuning](https://arxiv.org/abs/2608.05045)
**Authors:** Yuxuan Huang, Xingyu Zeng, Tianhang Zheng, Chaochao Lu | **Published:** 2026-08-05

A release-time defense for partially protected open-weight models: a Null Space Cubic Layer + Inverse Adapter blocks gradients from harmful samples during downstream fine-tuning while preserving forward behavior. Keeps post-finetuning attack success near pre-release levels across six model-dataset settings.

**Full breakdown:** [papers/2026/08/gradient-immunity-null-space.md](https://github.com/manthanghasadiya/intel/blob/main/papers/2026/08/gradient-immunity-null-space.md)

## 🔥 HOT TAKE + CONTENT IDEA

CoreBreak, PIMiner, and LoginTrap all converge on the same lesson: the model is no longer the attack surface — the dispatch and auth layer around it is. For Manny today: build a PIMiner-style strategy-library agent and point it at tool-dispatch provenance, specifically testing whether any SDK under test will execute a tool call that never came from a model turn (the exact CoreBreak class). Write it up as "3 ways your agent gets owned without the model running" — CoreBreak (forged tool calls), Paperclip (malicious imports), LoginTrap (auth-boundary phishing). That's a concrete, demoable red-team methodology post with fresh Black Hat research behind it.
