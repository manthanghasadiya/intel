### [📄 Nvidia's AVO harness scores 100% on ARC-AGI-3 public set](https://developer.nvidia.com/blog/nvidia-avo-reaches-100-on-arc-agi-3-demonstrating-a-frontier-level-general-purpose-architecture-for-long-horizon-autonomous-agents/)
**⏱ Read time:** 3 min

Nvidia's Agentic Variation Operators (AVO) — a harness with persistent memory plus a supervisor agent that nudges the main agent when it stalls — completed all 183 ARC-AGI-3 levels across 25 environments (100.00 RHAE) using Claude Opus 5, in 6,624 actions (~12% fewer than VISTA's 7,542). Without the harness, Opus 5 scores ~30%; OpenAI's models were under 10% before OpenAI found harness tweaks that tripled its scores. Same AVO architecture ran 7 days straight on GPU-kernel optimization, beating FlashAttention-4 by up to 10.5%.

**Why it matters:** Direct evidence that agent harness architecture — memory, supervision, recovery — moves performance more than the underlying model, which reframes where Manny's security investment should land.

## 🔐 SECURITY

### [📄 14 trojanized npm packages drop RedC2 4.0 Linux backdoor with LLM-driven C2](https://thehackernews.com/2026/08/14-trojanized-npm-packages-drop-redc2.html)
**⏱ Read time:** 3 min

Trend Micro found 14 functional npm packages (streak/calendar utilities) whose entry file launches a bundled RedShell Linux beacon — no install hook needed, a single import anywhere in the dependency graph executes it. RedC2 4.0 (sold for $99.99 on Hack Forums) includes "Red Agent," an LLM layer that turns natural-language commands into post-exploitation actions like recon and credential dumping. Cross-platform (Win/macOS/Linux), in-memory BOF/.NET/shellcode execution, SOCKS5 proxying.

**Why it matters:** AI-assisted C2 via supply chain is now commodity malware — dependency auditing must assume LLM-orchestrated post-exploitation.

### [📄 Microsoft Defender's own BTR.sys driver weaponized to delete security software at boot](https://thehackernews.com/2026/08/microsoft-defenders-own-driver-can-be.html)
**⏱ Read time:** 3 min

Check Point's "BTR Reforged" technique abuses Defender's legitimately signed boot-time remediation driver (BTR.sys, present since Windows 7) to perform arbitrary kernel-level file/registry operations from Ring 0 — a live demo deleted the entire Defender stack from a patched Win11 25H2 with Tamper Protection on. No vulnerability is exploited; it's an architectural trust boundary requiring admin/SeLoadDriverPrivilege. MSRC declined to service it; no patch planned. Sysmon detection guidance and BTR_CLI PoC are public.

**Why it matters:** Built-in signed drivers as offensive primitives defeat blocklist-based defenses — a pattern that will migrate to AI-agent runtimes.

### [📄 CISA KEV: TrueConf server flaws exploited by Head Mare to push PhantomCore](https://www.securityweek.com/cisa-urges-immediate-patching-of-exploited-trueconf-vulnerabilities/)
**⏱ Read time:** 2 min

CISA added CVE-2026-72529 and CVE-2026-72530 (both critical, RCE via port 4307/TCP on TrueConf Server) to its KEV catalog, ordering federal agencies to patch within 3 days / 2 weeks. Kaspersky tied the exploitation to hacktivist group Head Mare: attackers replaced a server file with a web shell, swapped legitimate client installers for ones carrying PhantomCore malware, and backdoored *nix hosts with C2 over the TrueConf protocol and GitHub. Patches shipped in June (5.3.9/5.4.9/5.5.5).

**Why it matters:** Video-conferencing and collaboration servers remain prime initial-access targets — worth checking exposure of anything listening on unusual ports.

### [📄 EnvHarness: Google Research wraps static environments to keep agents learning](https://arxiv.org/abs/2608.19880)
**⏱ Read time:** 2 min
**📄 Related paper:** [../../papers/2026/08/envharness-awakening-static-worlds.md](link)

EnvHarness is a programmable plug-in layer that reshapes static agent environments (states, rules, observations) without touching their logic or verifiers, plus EnvRigger, which diagnoses agent failures from trajectories and synthesizes harness components automatically. Up to 9.0-point gains on held-out instances with 9.8% fewer execution steps across ALFWorld, WebArena, SWE-bench and others, and it doubles as an optimization signal for RL.

**Why it matters:** Environment-as-code is the agent-side analog of attack-surface management — harnesses and environments, not just models, are where agent capability and risk are decided.

### [📄 COPA: continual learning defense against evolving prompt injection](https://arxiv.org/abs/2608.19982)
**⏱ Read time:** 2 min
**📄 Related paper:** [../../papers/2026/08/copa-continual-prompt-injection-defense.md](link)

COPA treats prompt-injection defense as a lifelong learning problem: GRPO-based optimization on newly observed attacks plus margin-weighted experience replay to retain defenses against older classes. Across lifelong attack streams it cuts attack success rate by up to 6.3x (4.4x average) versus state-of-the-art static defenses while preserving general capability.

**Why it matters:** Static guardrails are already obsolete against adaptive adversaries — Manny's agent stacks need defenses that update as attacks evolve.
