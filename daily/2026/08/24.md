### [📄 Critical Keycloak Password Reset Flaw Could Let Unauthenticated Attackers Take Over Any Account](https://thehackernews.com/2026/08/critical-keycloak-password-reset-flaw.html)
**⏱ Read time:** 2 min

CVE-2026-18963 (CVSS 9.1, CWE-640) is an improper state-validation bug in Keycloak's reset-credentials flow: a crafted request to the endpoint transitions the session straight to the password-update phase, never requiring the emailed action token — full account takeover of any user, including admins, with zero interaction. Fixed in 26.7.2 / RHBK 26.4.15 & 26.6.6. Found by Escape's Enzo Mongin; no in-the-wild exploitation confirmed as of Aug 24.

**Why it matters:** Keycloak sits in front of thousands of enterprise SSO deployments — an unauthenticated "reset anyone's password" primitive is a domain-admin-in-one-request scenario for red teams.

## 📄 PAPERS

### [AEGIS: Preventing Cross-Domain Resource Abuse in MCP](https://arxiv.org/abs/2608.20481)
**Authors:** Shriti Priya, Teryl Taylor, Frederico Araujo (IBM Research) | **Published:** Aug 24, 2026 (submitted Aug 20)

First dedicated framework for MCP tool-modality resource abuse — agents weaponizing oversized search radii, videos, or multimodal inputs to degrade or DoS backend services; argues current mitigation is inconsistent across modalities and proposes enforceable cross-domain policies.

**Full breakdown:** [papers/2026/08/aegis-preventing-cross-domain-resource-abuse-in-mcp.md](link)

### [The Claws in Plain Sight: Unauthorized Context Disclosure through LLM Agent Tool Calls](https://arxiv.org/abs/2608.20658)
**Authors:** Ben Dong, Zhonghao Guo, Tianyi Lu, Qian Wang | **Published:** Aug 24, 2026 (submitted Aug 21)

An "authority-pressure" attack: task-adjacent content frames protected attributes as operationally required, tricking agents into embedding them in otherwise-valid tool-call arguments. Across 120 calls spanning 5 DeepSeek/Claude configs, session-level disclosure rates hit 20.8%–75.0%; stronger privacy instructions reduce but don't eliminate leakage.

**Full breakdown:** [papers/2026/08/claws-in-plain-sight-unauthorized-context-disclosure.md](link)

---

### [ARQ: Agentic CodeQL Query Refinement for C/C++ Vulnerability Detection](https://arxiv.org/abs/2608.20637)
**Authors:** Chunyi Wang, Yunfei Ke, Junfeng Yang (Columbia), Yun-Yun Tsai, Penghui Li (IBM) | **Published:** Aug 24, 2026 (submitted Aug 21)

Agentic framework that auto-refines C/C++ CodeQL queries using execution-grounded evidence: synthesize programs where execution disagrees with the query verdict to expose false-positive and false-negative weaknesses, then run an LLM refinement loop to fix the queries.

**Full breakdown:** [papers/2026/08/arq-agentic-codeql-query-refinement.md](link)

## 🔥 HOT TAKE + CONTENT IDEA

The Claws-in-Plain-Sight paper (20–75% tool-call context leakage across Claude/DeepSeek) pairs perfectly with AEGIS's MCP resource-abuse model: **build a "tool-call argument leak + resource abuse" audit harness for MCP servers** — feed MCP tool schemas into a pressure/policy matrix, measure what protected fields end up in tool arguments and what oversized modalities get through, and ship it as a repeatable red-team check. That's a deliverable no vendor tool covers today.
