## 🔐 SECURITY

### [📄 ChainDrop worm crawls into npm supply chain, evades standard defenses](https://www.theregister.com/security/2026/08/15/chaindrop-worm-crawls-into-npm-supply-chain-evades-standard-defenses/5287958)
**⏱ Read time:** 4 min

A new Shai-Hulud variant dubbed "ChainDrop" poisoned 444 npm packages (~2B downloads/month) from multiple publishers. It propagates by rebuilding package *tarballs* — never touching source repos — and by writing malicious hooks into `.claude/settings.json` and `.vscode/tasks.json` in Git branches: simply *opening* an infected branch in VS Code or Claude Code triggers credential harvesting (npm tokens, cloud keys, GitHub creds). Microsoft and ActiveState are tracking it; infected packages were yanked, and SafeDep maintains an IOC list.

**Why it matters:** The worm weaponizes the exact tools Manny's ecosystem runs on — agent IDEs and their config files are now a first-class malware execution path, invisible to source review and most dependency scanners.

### [📄 Labels Are Not Endpoints: Treatment Leakage and Construct Validity in MCP Agent Security Evaluation](https://arxiv.org/abs/2608.12880)
**⏱ Read time:** 3 min
**📄 Full breakdown:** [papers/2026/08/labels-are-not-endpoints-mcp-agent-eval.md](../../papers/2026/08/labels-are-not-endpoints-mcp-agent-eval.md)

An audit of a preserved MCP agent security-evaluation campaign found the grader leaked treatment metadata into the ATTACK_SUCCESS class: 58 historical "attack success"/"hijack attempt" labels were corrected to authorized benign completions under a treatment-blind reconstruction, and the locked v2 census contains zero ATTACK_SUCCESS records. A blinded dual-reviewer concordance check disagreed with the locked codebook.

**Why it matters:** If eval labels are conditioned on treatment metadata, "attack success" numbers in MCP agent security benchmarks are not behavioral facts — Manny's own eval harnesses need treatment-blind grading.

**Authors:** Xutao Mao, Liangjie Zhao, Xiang Zheng, Cong Wang | **Published:** 2026-08-13

Self-improving agents distill successful trajectories into reusable skills — so an unsafe success becomes persistent policy after its trigger input disappears. ### [Correct Is Not Governed: Provenance Integrity in Agentic Workflows](https://arxiv.org/abs/2608.12761)
**Authors:** Jesus Salas | **Published:** 2026-08-13

Argues outcome-correctness is insufficient for institutional agent deployments: a correct action can rest on the wrong authority, an unsupported completion claim, or stale facts. "Matrix" is a deterministic causal-state layer that records authority/fact dependencies, verifies completion evidence, and selectively invalidates dependent work. Governed workflows matched direct ones on outcomes but preserved governing evidence and refused unsupported closure — yet a role-separated transfer test showed its completeness contract severely over-blocks out-of-context inputs.
