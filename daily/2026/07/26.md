## 🔐 SECURITY

### [📄 Fastjson 1.x RCE (CVE-2026-16723, CVSS 9.0) — Actively Exploited, No Patch](https://thehackernews.com/2026/07/fastjson-1x-rce-vulnerability-targeted-in.html)
**⏱ Read time:** 2 min

Security firms ThreatBook and Imperva report attackers actively targeting a critical RCE vulnerability in Alibaba's Fastjson 1.x JSON library for Java. A malicious JSON request can execute code without authentication in affected Spring Boot applications. The vulnerability affects Fastjson 1.2.68 through 1.2.83 and requires SafeMode disabled (default). As of July 25, Alibaba has not released a fixed 1.x version. Mitigation: enable SafeMode with `-Dfastjson.parser.safeMode=true` or migrate to Fastjson2.

**Why it matters:** No patch + active exploitation = immediate risk for any Java/Spring Boot infrastructure Manny manages or targets. Easy mitigation available but requires awareness.

**Exploit/PoC:** Send crafted JSON to Fastjson parser in Spring Boot app — no auth required.

### [📄 GitLab RCE PoC Published — Authenticated Users Can Run Commands as Git](https://thehackernews.com/2026/07/researcher-publishes-gitlab-rce-poc.html)
**⏱ Read time:** 2 min

Researchers at depthfirst published working exploit code for a GitLab vulnerability patched six weeks ago (June 10) but never flagged as a security fix. Any authenticated user who can push to a project can execute commands as the git user on self-managed GitLab 18.11.3. The exploit chain uses crafted Jupyter notebook commits that leak heap pointers, enabling memory layout mapping and payload delivery. No CVE assigned; GitLab listed the Oj 3.17.3 bump under bug fixes, not security fixes. Operators who triaged against the security table had no reason to treat it as urgent.

**Why it matters:** Classic security-through-obscurity failure — silently patching a security flaw in a bug-fix release means most self-managed instances remain vulnerable. Manny should check GitLab versions in target infrastructure.

### [📄 SourTrade Malvertising: Browser Builds Malware from Pieces Using Bun Runtime](https://thehackernews.com/2026/07/malvertising-sends-malware-in-pieces.html)
**⏱ Read time:** 2 min

A malvertising campaign dubbed SourTrade makes victims' browsers build the final Windows executable themselves using a legitimate Bun runtime, rather than serving a complete malicious file. Active since late 2024, it impersonates TradingView, Solana, and Luno across 12 countries in 25 languages. Landing pages fingerprint visitors, showing empty pages to researchers while selected targets receive convincing copies of impersonated services.

**Why it matters:** Novel delivery technique (in-browser assembly via Bun) that bypasses traditional file-based detection. Important for Manny's threat hunting methodology.
