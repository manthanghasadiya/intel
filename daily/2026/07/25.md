Anthropic released Claude Opus 5 on July 24, positioning it as the "daily driver" model that delivers nearly all the intelligence of the top-of-the-line Claude Fable 5 at half the cost ($5/$25 per million tokens). ## 🔌 MCP / AI AGENTS

### [📄 Model Context Protocol Is Going Stateless to Make Scaling Simpler](https://www.infoworld.com/article/3960880/model-context-protocol-is-going-stateless-to-make-scaling-simpler.html)
**⏱ Read time:** 2 min

The Model Context Protocol (MCP) is adopting a stateless architecture to simplify scaling of AI agent tool integrations. This is a significant architectural shift from the original stateful session model. Stateless MCP reduces server resource requirements and makes horizontal scaling more straightforward. The change aligns MCP with RESTful patterns, though it introduces new considerations for maintaining conversational context across stateless calls.

**Why it matters:** If Manny's agent toolchain uses MCP, the stateless shift changes both the security model (less state to leak between sessions) and the integration pattern (context must be explicitly managed). Worth evaluating the migration impact.
