### [📄 Microsoft Copilot for Word Can Copy Hidden Prompts Into New Documents](https://thehackernews.com/2026/07/microsoft-copilot-for-word-can-copy.html)
**⏱ Read time:** 3 min

Hidden instructions in a Word document can make Microsoft 365 Copilot rewrite figures in a report, then copy the same instructions into the finished file. Researcher Håkon Måløy disclosed the technique on July 28, 144 days after reporting it to Microsoft. Microsoft deployed two mitigations (prompt blocking + GPT-5.5 model upgrade), but the attack class still reproduced on GPT-5.6 the next day. The payload doesn't need a CVE — Word strips colour and font size before sending text to the LLM, making white-on-white instructions legible to the model but invisible to users. The chain propagates: an infected internally-generated document can carry the payload into the next Copilot session, breaking provenance trails.

**Why it matters:** This is prompt injection weaponized as document-propagated malware — directly relevant to how Manny evaluates AI supply chain security and agent tooling risks.

## 🔐 SECURITY

### [📄 Critical Ruflo Flaw Lets Attackers Spawn Rogue AI Swarms](https://www.securityweek.com/critical-ruflo-flaw-lets-attackers-spawn-rogue-ai-swarms/)
**⏱ Read time:** 3 min

Unauthenticated attackers can send HTTP requests to an exposed Ruflo endpoint to execute commands inside its MCP bridge container — effectively spawning rogue AI agent swarms. The flaw sits at the intersection of MCP infrastructure and container security. Ruflo is an orchestration layer for multi-agent AI systems, making this a supply-chain-critical vulnerability for anyone running agent fleets.

**Why it matters:** Directly relevant to Manny's MCP/agent security work. An unauthenticated MCP bridge RCE is the exact kind of vulnerability to test for in agent infrastructure.

### [📄 Hackers Exploit AnySign4PC via Hacked Korean Sites to Install Backdoors Without Prompts](https://thehackernews.com/2026/07/hackers-exploit-ansign4pc-via-hacked-korean-sites.html)
**⏱ Read time:** 2 min

A state-sponsored campaign compromised trusted South Korean websites, using them to exploit locally installed AnySign4PC financial-security software (versions 1.1.4.4-1.1.4.6). Visitors got infected with SIGNBT or COPPERHEDGE backdoors without any user interaction. KISA reports evidence of related attacks at 72 organizations in 2026, with 15 legitimate websites used as watering holes.

**Why it matters:** Drive-by download via trusted infrastructure — classic watering hole technique with financial-security software as the vector. Relevant for client-side attack surface analysis.

**Exploit/PoC:** Targets AnySign4PC 1.1.4.4-1.1.4.6. Fixed in 1.1.5.0.

### [Lilith: Backdoor Generalization under Training-Inference Trigger Shift](https://arxiv.org/abs/2607.26099)
**Authors:** Zhou Feng, Jiahao Chen, Chunyi Zhou et al. | **Published:** July 30, 2026

Shows that backdoors implanted during training can generalize to entirely unseen trigger families at inference time — a blind spot in existing backdoor evaluation. Lilith uses a single training anchor to construct a bounded inference-only trigger family, achieving high attack success across datasets and architectures without requiring trigger diversity during training.
