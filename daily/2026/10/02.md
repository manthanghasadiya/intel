## 🤖 AI NEWS

### [📄 Anthropic ships Claude Code "mods" — TypeScript plugins that rewrite prompts and gate tool calls](https://claude.com/blog/claude-code-mods)
**⏱ Read time:** 3 min

Anthropic released "mods" for Claude Code: JavaScript/TypeScript event handlers, packaged as plugins, that can observe, rewrite, or take over internal events. Mods can rewrite a prompt before it reaches the model, block or retry tool calls, approve/deny permission requests, and redact secrets from tool output. Built-in features such as the diff tool now run as mods and can be replaced or removed; mods ship by default in Claude Code 2.1.287+ via CLI or desktop.

**Why it matters:** This lets Manny enforce policy *inside* the agent loop — a mod that blocks risky shell commands, redacts secrets, or requires approval on specific tools — rather than bolting guardrails on the outside.

## 🔐 SECURITY

### [📄 Fortinet FortiMail zero-day (CVE-2026-104286, CVSS 9.8) exploited; CISA adds it to KEV](https://thehackernews.com/2026/10/critical-fortimail-zero-day-flaw.html)
**⏱ Read time:** 3 min

CVE-2026-104286 is a path-traversal plus NULL-byte flaw (CWE-22/CWE-158) that lets an unauthenticated attacker write arbitrary files via crafted HTTP/HTTPS requests. CISA added it to KEV on Oct 1 with a federal deadline of Oct 4; no fixed builds exist for every branch, so Fortinet advises disabling IBE and blocking management-interface internet access. Published IoCs include IPs `79.141.169[.]187` and `45.129.0[.]192`, and dropped files such as `/data/etc/ld.so.preload` and a modified `/bin/smit`.

**Why it matters:** A critical edge appliance exploitable *right now* — if Manny or any client runs internet-exposed FortiMail, treat this as an emergency patch/isolate.

### [📄 [Paper] Chaining Skills to Hijack LLM Agents (APEX)](https://arxiv.org/abs/2610.01564)
**⏱ Read time:** 2 min
**📄 Full breakdown:** [papers/2026/10/chaining-skills-hijack-llm-agents.md](../../papers/2026/10/chaining-skills-hijack-llm-agents.md)

APEX builds adversarial *skill chains*: an upstream open-source skill induces the agent to write a task-progress record that carries a false claim of user approval, and a downstream skill uses that record to steer an attacker-chosen action. Across six models on SkillsBench the chains induced the target action in 512/690 attempts (74.2%); on GPT-5.4 the full chain hit 84.3% vs 17.4% when the workflow was merged into one skill.

**Why it matters:** Single-artifact scanners miss this — the attack lives in the *handoff between* skills, so MCP/skill vetting must reason about provenance across the chain, not just per-tool.

## 📄 PAPERS

### [The Innocent Courier: Covert Exfiltration Through Legitimate LLM Web Fetching](https://arxiv.org/abs/2610.01768)
**Authors:** Alessandro Pegoraro, Daryan Merx, Phillip Rieger, Ahmad-Reza Sadeghi (TU Darmstadt) | **Published:** Oct 1, 2026

LLMLeak abuses the LLM's own web-fetch tool to establish a covert channel for local malware that has no direct internet access: a client-side component hides a secret in a URL and presents it as needed for a benign task, then reads it back via attacker-controlled DNS/HTTP. Attack success 79.7% across eleven open-parameter models.

**Authors:** Fengpeng Li, Qizhou Wang, Yuke Hu, Kemou Li, Jun Liu, Haiwei Wu, Jiantao Zhou, Di Wang | **Published:** Oct 1, 2026

PACE mediates every tool call immediately before execution, combining path confinement (an executable cut of influence paths) with capability/effect verification against authority compiled from the authenticated request. It wins on attack success in 62/79 eligible columns and loses at most 3 points of native utility.

**Full breakdown:** [papers/2026/10/pace-provenance-aware-capability-enforcement.md](../../papers/2026/10/pace-provenance-aware-capability-enforcement.md)

**Authors:** Taolin Zhang, Jiuheng Wan, Hanyu Wang, Tingyuan Hu, Chengyu Wang | **Published:** Oct 1, 2026

OverAct benchmarks "proactive over-authorization" — agents retrieving more private data than the request needs — across eight privacy-sensitive domains, finding every model exceeds authorized scope, with request specificity as the strongest predictor. Their SelfAudit method cuts privacy-oriented excess by 43%.

## 🔥 HOT TAKE + CONTENT IDEA

**Hot take:** Yesterday's agent-security theme was "the agent did too much." Today it's "the *scaffolding* did too much" — APEX hijacks the skill-to-skill handoff, LLMLeak turns the web-fetch tool into an exfil channel, and Claude Code mods hand you the same event hooks an attacker would love to poison. The lesson: audit the *interfaces* (tool calls, skill handoffs, fetch tools), not just the artifacts.

**Content idea:** Write a short teardown — "Your agent's web-fetch tool is a covert channel" — using the LLMLeak threat model: show a benign-looking "read this doc to continue" fetch that encodes a secret in the query string, then demo a Claude Code mod that rewrites/denies such fetches. One diagram, one 20-line mod, one call to action on egress allow-listing. Perfect cross-post for a red-team audience.
