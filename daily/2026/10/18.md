### [📄 Websites are closing their doors to AI agents](https://www.theverge.com/ai-artificial-intelligence/1013195/ai-agents-blocked-web)
**⏱ Read time:** 3 min

Meta's Muse, xAI's Grok, OpenAI's Dots and Instinct have all hit blocks on major sites. ## 🔐 SECURITY

### [📄 PEERSTITCH: memory-resident ARM64 malware delivered through a patched FortiOS flaw](https://thehackernews.com/2026/10/attackers-exploit-fortios-flaw-to.html)
**⏱ Read time:** 3 min

Unit 42 tied a telecom MSP intrusion (CL-STA-0954 / UNC5820) to PEERSTITCH, an ARM64 implant that leaves no binary on disk, opens no listening port and makes no outbound connections — it rides traffic generated by legitimate processes. Entry was CVE-2024-47575 (FortiJump) into FortiManager; the actor exfiltrated configs, ciphertext credentials and management databases covering 500+ FortiGate firewalls, then used CVE-2025-61624 (FortiOS CLI path traversal, patched April 2026) for the follow-on. CISA added the Fortinet flaw to KEV on Oct 16 with a **due date of Oct 19**.

**Why it matters:** This is the detection-evasion pattern to internalize — no IOCs on disk, no beacons, no ports. If your telemetry is file- and network-flow-centric, PEERSTITCH-class implants are invisible by construction.

### [📄 CVE-2026-111911: phpMyFAQ WebAuthn bypass hands over any account, CVSS 9.8](https://nvd.nist.gov/vuln/detail/CVE-2026-111911)
**⏱ Read time:** 3 min

phpMyFAQ 4.0.0 through 4.1.8 (fixed in 4.1.9) attaches WebAuthn credentials to *any* username without authentication or challenge validation — a forged `fmt=none` attestation is accepted, so an attacker registers their own passkey against `admin` and logs in, bypassing both password and TOTP. No user interaction, no browser, scriptable with a plain HTTP client and ECDSA P-256. Precondition: `security.enableWebAuthnSupport=true` (admin opt-in, non-default).

**Why it matters:** The passkey rollout is being sold as phishing-proof MFA, but the registration ceremony is the soft spot — a lesson that applies directly to any agent-auth or device-binding scheme you assess.

### [📄 CikaBika: a Rust RAT that uses Discord as its command center](https://securityaffairs.com/201210/security/rust-based-cikabika-bot-turns-discord-into-a-command-center.html)
**⏱ Read time:** 2 min

Darktrace documented a campaign starting from a disk image disguised as a business proposal: a malicious Windows shortcut, a Nim loader, and a PowerShell UAC bypass to plant the payload inside Microsoft Edge's install directory. The Rust RAT then registers the host with Discord and takes commands over chat messages — arbitrary execution, file theft, screen capture.

**Why it matters:** Commodity C2 over a SaaS chat platform survives most egress filtering and looks like normal enterprise traffic. Worth a detection rule on Discord API calls from non-browser processes.

## 🔌 MCP / AI AGENTS

### [📄 Claude Code 2.1.302 fixes the MCP negotiation bug that silently killed every tool call](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)
**⏱ Read time:** 2 min

Two changes matter for agent operators: MCP servers negotiating protocol version `2026-07-28` but omitting `resultType`, `ttlMs` or `cacheScope` no longer show zero tools / fail every call; and `CLAUDE_CODE_AUTO_MODE_MODEL` now lets you pin the model used by the client-side auto-mode classifier (previously you had no control over what was deciding to run your tools). Fork subagents are now on by default in `claude -p`, the Agent SDK, desktop and VS Code.

**Why it matters:** Auto-mode is the gate that decides whether a tool call executes — pinning its classifier model is the first real knob for making agent approval behavior deterministic and auditable.

**⏱ Read time:** 1 min

A new Python MCP server (created Oct 17) that indexes locally decrypted WeChat 4.x/3.x and DingTalk 7.x SQLite databases with FTS5 and exposes read-only search to Claude Desktop, Cursor, Cline and Pi. **Why it matters:** This is the "local data, agent surface" pattern done with the right default — read-only and offline. It's also a clean example of the attack surface every desktop agent now inherits: whoever controls that SQLite file controls the agent's context.
