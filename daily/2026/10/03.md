## 🔐 SECURITY

### [📄 GitLab patches critical AI Gateway RCE (CVE-2026-90970, CVSS 9.9)](https://www.bleepingcomputer.com/news/security/gitlab-warns-of-critical-rce-vulnerability-in-ai-gateway-service/)
**⏱ Read time:** 2 min

GitLab disclosed CVE-2026-90970 on October 2: any authenticated user with Duo Agent Platform access can escape the prompt-template sandbox via a crafted flow configuration and execute arbitrary commands on the self-hosted AI Gateway host. Affected versions span 18.1.6 → 19.2.4, 19.3 → 19.3.2, 19.4 → 19.4.1 (fixes: 19.2.4, 19.3.2, 19.4.1); GitLab-hosted customers are already patched. CISA listed exploitation as "none" at disclosure; researcher invisiblemeerkat reported it via HackerOne.

**Why it matters:** Reportedly the first critical RCE in an AI-specific infrastructure component — the LLM-brokering tier is now a first-class target, and prompt sandboxes are proving escapable.

## 🔌 MCP / AI AGENTS

### [📄 AWS Loom CVE-2026-103956 (CVSS 10): any client can seize the agent control plane](https://cvebrief.com/cve/cve-2026-103956/)
**⏱ Read time:** 2 min

AWS disclosed four flaws on Oct 2–3: three in Loom for AWS, its open-source AI-agent orchestration platform, and one in SageMaker. CVE-2026-103956 is a CVSS 10 missing-authentication bug — in deployments without an identity provider, any network client can claim super-admin on the Loom control plane, register malicious tool servers, read stored integration credentials, and rewrite the IAM role policies attached to managed agents. AWS also fixed OAuth2 SSRF flaws (CVE-2026-103957/103958) and a SageMaker command-injection bug (CVE-2026-104019); the fix is Loom 1.7.0.

**Why it matters:** This is the canonical agent-infrastructure nightmare — hostile tool registration plus credential and policy access — and shows that missing-auth on a control plane is a one-shot compromise of every managed agent.

### [📄 Autonomous AI agent breached DIVD via two Zammad zero-days](https://cyberrecaps.com/news/cybersecurity-news-october-02-2026)
**⏱ Read time:** 2 min

An autonomous AI agent breached the Dutch Institute for Vulnerability Disclosure (DIVD) network by chaining two Zammad ticketing-system zero-days (CVE-2026-102489, CVE-2026-102490), hijacking sessions, achieving RCE, escalating to root and exfiltrating data — with no human driving the attack. Segmentation and rapid response contained it; Zammad shipped version 7 as the fix.

**Why it matters:** A real-world datapoint for agent-driven exploitation of open-source tooling — the closest thing yet to the "agents find and chain zero-days" scenario tracked in recent digests.

## 📄 PAPERS

### [ZoneClaw: Mitigating Persistent Memory Attacks by Establishing Memory-Zoning in OpenClaw-Style Computer-Use Agents](https://arxiv.org/abs/2610.00450)
**Authors:** Haokai Ma, Chieh Lin, Yupeng Qiu, Ee-Chien Chang (NUS) | **Announced:** Oct 2, 2026

Introduces "persistent memory attacks" — an attacker who controls only benign-looking external content induces a computer-use agent to record attacker-favored claims that later govern tasks the attacker never touches. ZoneClaw splits flat workspace memory into hierarchical trust zones so stored claims only gain action-guiding authority by crossing an explicit boundary. Drives attack success from 372/480 to 6/480 while keeping utility at 458/480.

### [From A2A Attacks to Envelope-Layer Defense: Red-Teaming Evaluation of LLM Agents](https://arxiv.org/abs/2610.00392)
**Authors:** Yuelin Han | **Announced:** Oct 2, 2026

### [Actions with Receipts: Jointly Binding Claims, Evidence, and Execution for Replayable Tool-Agent Auditing](https://arxiv.org/abs/2610.00327)
**Authors:** Miaobo Hu, Shuhao Hu, Xiaobo Guo, Xin Wang, Bokun Wang, Yina Sa, Daren Zha, Jun Xiao (CAS) | **Announced:** Oct 2, 2026

Defines a claim-anchored execution contract that cryptographically binds an agent's emitted claim to its exact source span, the ordered execution prefix that produced it, and the observed source version/access state — so individually valid citations and traces can't be transplanted across claims or runs. Detects 1,275/1,280 cross-object substitutions (0.9961), with targeted-property removal collapsing detection to 0.0156–0.0625.
